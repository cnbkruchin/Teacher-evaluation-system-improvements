# คู่มือการใช้งานสำหรับครูผู้ประเมิน (ไฟล์ต้นฉบับ)

ไฟล์ PDF ที่ใช้แจกครูอยู่ที่ [`docs/คู่มือการใช้งานสำหรับครูผู้ประเมิน.pdf`](../คู่มือการใช้งานสำหรับครูผู้ประเมิน.pdf)
(14 หน้า · A4 · ภาษาไทย · มีสารบัญในตัวไฟล์ · ปรับปรุงสำหรับ v3.3)

โฟลเดอร์นี้เก็บไฟล์ต้นฉบับไว้ให้แก้ไขและพิมพ์ใหม่ได้เอง

| ไฟล์ | คำอธิบาย |
|---|---|
| `manual.html` | เนื้อหาคู่มือทั้งหมด แก้ไขด้วยโปรแกรมแก้ไขข้อความทั่วไป |
| `shots/*.jpg` | ภาพหน้าจอที่ใช้ในคู่มือ |

## วิธีแก้ไขและสร้าง PDF ใหม่

**วิธีที่ง่ายที่สุด** (ไม่ต้องติดตั้งอะไรเพิ่ม)

1. แก้ข้อความใน `manual.html` (เปิดด้วย Notepad, VS Code หรือโปรแกรมแก้ไขข้อความใดก็ได้)
2. เปิดไฟล์ด้วย Google Chrome หรือ Microsoft Edge
3. กด `Ctrl + P` → เลือกปลายทางเป็น **บันทึกเป็น PDF**
4. ตั้งค่า: ขนาดกระดาษ **A4** · ระยะขอบ **กำหนดเอง (บน 17 มม. ล่าง 20 มม. ซ้าย-ขวา 15 มม.)**
   · เปิด **กราฟิกพื้นหลัง** (Background graphics) เพื่อให้สีและตารางแสดงครบ

> ต้องเชื่อมต่ออินเทอร์เน็ตขณะเปิดไฟล์ เพื่อให้เบราว์เซอร์โหลดฟอนต์ Sarabun
> หากออฟไลน์ ระบบจะใช้ฟอนต์สำรองของเครื่องแทน (หน้าตาต่างไปเล็กน้อยแต่อ่านได้ปกติ)

## สิ่งที่ควรแก้ก่อนแจกครู

- **หน้าปก** — เติมชื่อโรงเรียนและชื่อผู้ดูแลระบบ/ผู้ประสานงาน
  (ในไฟล์ PDF มีเส้นประเว้นไว้ให้เขียนด้วยมือได้เช่นกัน)
- **ภาคผนวก** — ปรับรายละเอียดให้ตรงกับแนวปฏิบัติของโรงเรียน
- **จำนวนข้อประเมินของแต่ละบทบาท** (หัวข้อ 3.4) — หากโรงเรียนปรับเกณฑ์การประเมิน
  หรือกำหนดกลุ่มผู้ประเมินของชุดใหม่ ให้แก้ตัวเลขในตารางให้ตรงกับที่ตั้งค่าไว้จริง
- **ตัวอย่างการแปลงคะแนน** (หัวข้อ 6 คำถามที่พบบ่อย) — แก้ตัวเลข "คะแนนเต็มต่อข้อ"
  และ "คะแนนเต็มที่หน่วยงานกำหนด" ให้ตรงกับที่โรงเรียนตั้งไว้ในเมนู 🧩 ชุดประเมิน

## ถ่ายภาพหน้าจอใหม่

ภาพในคู่มือถ่ายจากระบบจริงที่รันด้วยข้อมูลตัวอย่าง หากหน้าจอเปลี่ยนไปหลังอัปเดตระบบ
ให้ถ่ายภาพใหม่แล้ววางทับไฟล์เดิมในโฟลเดอร์ `shots/` โดยใช้ชื่อไฟล์เดิม

| ไฟล์ | หน้าจอ |
|---|---|
| `login.jpg` | หน้าเข้าสู่ระบบ (แท็บผู้ประเมิน) |
| `evaluate.jpg` | หน้าแบบประเมิน (เลือกชุดประเมินและครูแล้ว) |
| `history.jpg` | ผลที่ฉันประเมินแล้ว |
| `duty.jpg` | ตารางเวรประจำวัน |
| `password.jpg` | หน้าเปลี่ยนรหัสผ่าน |
| `phone.jpg` | หน้าแบบประเมินบนมือถือ |
