# การย้ายข้อมูลจากระบบเดิม (v2 → v3)

ระบบใหม่ออกแบบให้ **อัปเกรดทับระบบเดิมได้ทันที** โดยข้อมูลเดิมไม่สูญหาย
การติดตั้งเป็นแบบปลอดภัย (idempotent) — สั่งซ้ำกี่ครั้งก็ไม่ทำข้อมูลเสียหาย

## ขั้นตอน

1. **สำรองข้อมูลก่อนเสมอ** — ที่ Google Sheets เลือก **ไฟล์ → สร้างสำเนา**
2. เปิด **ส่วนขยาย → Apps Script** แล้ว **ลบไฟล์สคริปต์เดิมทั้งหมด**
   (`Code.gs`, `AdminLogin.html`, `AdminPanel.html`, `EvaluatorLogin.html`, `EvaluationForm.html`)
3. เพิ่มไฟล์ใหม่จากโฟลเดอร์ `src/` ตาม [INSTALL.md](INSTALL.md)
4. กลับไปที่ Google Sheets → รีเฟรช → เมนู **🏫 ระบบประเมินผล → ⚙️ ติดตั้ง / อัปเกรดระบบ**
5. อ่านสรุปผลการย้ายข้อมูลที่ระบบแสดง

## ระบบทำอะไรให้บ้าง

| ข้อมูล | การดำเนินการ |
|---|---|
| ชีทเดิมทั้งหมด | เก็บไว้ตามเดิม **เพิ่มเฉพาะคอลัมน์ที่ยังขาด** ต่อท้าย (ข้อมูลเดิมไม่ขยับ) |
| รายชื่อครู | เติม **รหัสครู** (`TCH-0001`...) ให้ทุกคน และคัดลอก `ระดับชั้นที่สังกัด` → `ระดับชั้นที่ปรึกษา`, `เวรประจำวัน` → `เวรประจำวัน (ค่าเริ่มต้น)` |
| ผู้ประเมิน | เติม **รหัสผู้ประเมิน** (`EVA-0001`...) และคัดลอก `ระดับชั้น/วัน` → `ขอบเขต (ระดับชั้น/วัน)` |
| รหัสผ่านเดิม | **ยังใช้เข้าสู่ระบบได้ตามเดิม** และถูกอัปเกรดเป็นการเข้ารหัสแบบมี salt อัตโนมัติเมื่อเข้าสู่ระบบครั้งถัดไป |
| ผลการประเมินเดิม | เติม **รหัสการประเมิน** (`EVR-0001`...), แยก `"1/2568"` เป็นภาคเรียน `1` + ปีการศึกษา `2568`, เชื่อมกับรหัสครู/รหัสผู้ประเมิน |
| คะแนนที่เคยเป็นสูตร | **คำนวณใหม่และเก็บเป็นค่าคงที่** (สูตรเดิมจะพังเมื่อย้ายหรือจัดเก็บข้อมูล) พร้อมกำหนดระดับผลใหม่ตามเกณฑ์ |
| เวรประจำวัน | สร้างตารางเวรให้ **ภาคเรียนปัจจุบัน และทุกภาคเรียนที่พบในผลการประเมินเดิม** จากค่าเวรของครู |
| ประวัติการใช้งานเดิม | ชีท `ประวัติการประเมิน` ถูกเปลี่ยนชื่อเป็น **`ประวัติการใช้งาน (ระบบเดิม)`** และเก็บไว้ครบ (ไม่ถูกเขียนทับ เพราะโครงสร้างคอลัมน์ต่างกัน) |
| ชีทใหม่ | สร้าง `เวรประจำวันรายภาคเรียน` และ `คลังผลการประเมิน` เพิ่มให้ |

## สิ่งที่ควรทำหลังอัปเกรด

1. เข้าสู่ระบบผู้ดูแลด้วย **รหัสผ่านเดิม** (ระบบไม่สร้างรหัสใหม่ทับ)
2. ตั้งค่า **อีเมลกู้คืนรหัสผ่าน** ที่หน้า "ตั้งค่าและความปลอดภัย" แล้วกดทดสอบส่งอีเมล
3. ตรวจ **ปีการศึกษา/ภาคเรียนปัจจุบัน** ให้ถูกต้อง
4. เปิดหน้า **เวรประจำวันรายภาคเรียน** ตรวจตารางเวรที่ระบบสร้างให้ และเติมรายละเอียด
   (บทบาทในเวร จุดปฏิบัติหน้าที่ เวลา) ตามจริง
5. เปิดหน้า **ผลการประเมิน** ตรวจว่าคะแนนและระดับผลตรงกับของเดิม
6. แจ้งผู้ประเมินว่ายังใช้รหัสผ่านเดิมได้ และส่ง **ลิงก์เว็บแอป** ใหม่ให้

## คำถามที่พบบ่อย

**ถาม: ต้องให้ผู้ประเมินตั้งรหัสผ่านใหม่ไหม?**
ตอบ: ไม่ต้อง รหัสผ่านเดิมใช้ได้ทันที และระบบอัปเกรดวิธีเข้ารหัสให้เองเบื้องหลัง
แต่แนะนำให้ทุกคนเปลี่ยนรหัสผ่านเพื่อความปลอดภัย

**ถาม: ข้อมูลการประเมินเดิมจะหายไหม?**
ตอบ: ไม่หาย ทุกแถวยังอยู่ในชีทเดิม ระบบเพียงเติมข้อมูลที่ขาดและคำนวณคะแนนใหม่ให้ถูกต้อง

**ถาม: ภาคเรียนเดิมบันทึกเป็น "1/2568" ระบบใหม่แยกอย่างไร?**
ตอบ: แยกเป็นคอลัมน์ `ภาคเรียน` = 1 และ `ปีการศึกษา` = 2568 เพื่อให้กรองและออกรายงานรายภาคเรียนได้

**ถาม: อัปเกรดแล้วอยากกลับไปใช้ระบบเดิมได้ไหม?**
ตอบ: ได้ ซอร์สโค้ดระบบเดิมอยู่ในโฟลเดอร์ `legacy/` และควรใช้สำเนาไฟล์ที่สำรองไว้ในขั้นตอนที่ 1
