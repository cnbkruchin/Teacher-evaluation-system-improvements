# คู่มือการติดตั้ง

## สิ่งที่ต้องมี
- บัญชี Google (แนะนำเป็นบัญชีของโรงเรียน)
- ไฟล์ Google Sheets 1 ไฟล์สำหรับเก็บข้อมูลระบบ

---

## วิธีที่ 1 — คัดลอกไฟล์ด้วยตนเอง (ง่ายที่สุด ไม่ต้องติดตั้งโปรแกรมเพิ่ม)

### ขั้นที่ 1 เปิดตัวแก้ไขสคริปต์
1. เปิดไฟล์ Google Sheets ที่จะใช้เป็นฐานข้อมูล
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**

### ขั้นที่ 2 สร้างไฟล์ให้ครบ

### ขั้นที่ 3 ตั้งค่าไฟล์ appsscript.json
1. ในตัวแก้ไขสคริปต์ กด **⚙️ Project Settings**
2. ติ๊ก **Show "appsscript.json" manifest file in editor**
3. กลับไปที่ **Editor** เปิดไฟล์ `appsscript.json` แล้ววางเนื้อหาจาก `src/appsscript.json`

### ขั้นที่ 4 ติดตั้งระบบ
1. กลับไปที่ Google Sheets แล้ว **รีเฟรชหน้าเว็บ**
2. จะเห็นเมนูใหม่ **🏫 ระบบประเมินผล**
3. เลือก **⚙️ ติดตั้ง / อัปเกรดระบบ** → กด **ใช่**
4. ครั้งแรกจะมีหน้าต่างขออนุญาตเข้าถึงข้อมูล → กด **Review permissions → เลือกบัญชี → Advanced → Go to ... (unsafe) → Allow**
   (ข้อความ "unsafe" เป็นเรื่องปกติของสคริปต์ที่ยังไม่ได้ยื่นตรวจสอบกับ Google — โค้ดทำงานอยู่ในบัญชีของท่านเอง)
5. **จดรหัสผ่านผู้ดูแลระบบที่ระบบแสดง** (แสดงครั้งเดียวเท่านั้น)

### ขั้นที่ 5 เผยแพร่เป็นเว็บแอป (เพื่อให้ผู้ประเมินใช้งานผ่านลิงก์)
1. ในตัวแก้ไขสคริปต์ กด **Deploy → New deployment**
2. กดรูปเฟือง ⚙️ ข้าง "Select type" → เลือก **Web app**
3. ตั้งค่า
   - **Description**: ระบบประเมินผลการปฏิบัติงานครู v3
   - **Execute as**: **Me** (บัญชีเจ้าของไฟล์)
   - **Who has access**: **Anyone** — ผู้ประเมินยังต้องเข้าสู่ระบบด้วยรหัสผ่านของระบบอยู่ดี
     (หากโรงเรียนใช้ Google Workspace และต้องการจำกัดเฉพาะคนในองค์กร ให้เลือก **Anyone within [โรงเรียน]**)
4. กด **Deploy** แล้วคัดลอกลิงก์ที่ได้
5. ดูลิงก์ซ้ำได้ทุกเมื่อจากเมนู **🏫 ระบบประเมินผล → 🔗 ลิงก์เว็บแอปสำหรับผู้ประเมิน**

> **อัปเดตโค้ดในภายหลัง**: แก้ไขไฟล์ → **Deploy → Manage deployments → ✏️ แก้ไข → Version: New version → Deploy**
> ลิงก์เดิมจะยังใช้ได้เหมือนเดิม

## วิธีที่ 2 — ใช้ clasp (สำหรับผู้ที่ถนัดใช้บรรทัดคำสั่ง)

```bash
npm install -g @google/clasp
clasp login

# คัดลอกไฟล์ตัวอย่างแล้วใส่ Script ID ของโปรเจกต์
cp .clasp.json.example .clasp.json
# แก้ไข .clasp.json → ใส่ scriptId (ดูได้จาก Apps Script → Project Settings)

clasp push
```

`.clasp.json` ถูกกำหนดให้ `rootDir` เป็น `src` อยู่แล้ว จึงอัปโหลดเฉพาะไฟล์ที่ใช้งานจริง

## หลังติดตั้งเสร็จ — สิ่งที่ควรทำทันที

1. เมนู **🚀 เปิดระบบ** → เข้าสู่ระบบผู้ดูแลด้วยรหัสผ่านที่ได้รับ
2. หน้า **ตั้งค่าและความปลอดภัย**
   - ตั้ง **อีเมลกู้คืนรหัสผ่าน** แล้วกด **📧 ทดสอบส่งอีเมล** ให้แน่ใจว่าได้รับจริง
   - ตรวจ **ปีการศึกษา / ภาคเรียนปัจจุบัน**
   - เปลี่ยน **รหัสผ่านผู้ดูแลระบบ** เป็นรหัสที่ท่านจำได้
3. หน้า **📆 ปีการศึกษาและภาคเรียน** → ตรวจปีการศึกษา/ภาคเรียนปัจจุบัน
   และเปิดใช้งานภาคเรียนที่โรงเรียนใช้จริง (เปิด "ภาคฤดูร้อน" เพิ่มได้ถ้ามี)
4. หน้า **ครูผู้รับการประเมิน** → กด **📥 นำเข้ารายชื่อ** → ดาวน์โหลดเทมเพลต Excel/CSV
   กรอกข้อมูลแล้วอัปโหลดกลับ (หรือเพิ่มทีละคน / วางข้อความจาก Excel ก็ได้)
5. หน้า **เวรประจำวัน** → กด **🪄 สร้างจากค่าเริ่มต้นในทะเบียนครู** แล้วปรับรายละเอียด
6. หน้า **ผู้ประเมิน** → เพิ่มผู้ประเมิน (ระบบสุ่มรหัสผ่านให้ และส่งอีเมลอัตโนมัติหากกรอกอีเมลไว้)
7. ส่ง **ลิงก์เว็บแอป** ให้ผู้ประเมินพร้อมรหัสผ่านของแต่ละคน

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| ไม่เห็นเมนู 🏫 ระบบประเมินผล | รีเฟรชหน้า Google Sheets อีกครั้ง หรือตรวจว่าไฟล์ `11_WebApp` มีฟังก์ชัน `onOpen` |
| เปิดระบบแล้วหน้าว่าง | ตรวจว่าสร้างไฟล์ HTML ครบทั้ง 9 ไฟล์ และสะกดชื่อถูกต้อง |
| นำเข้าไฟล์ Excel ไม่ได้ | ระบบแปลงไฟล์ผ่าน Google Drive — ตรวจว่า `appsscript.json` มีสิทธิ์ `drive` และ `script.external_request` แล้ว deploy เวอร์ชันใหม่ (ถ้ายังไม่ได้ ให้บันทึกไฟล์เป็น .csv แทนได้) |
| เปิดจากเมนูใน Sheets แล้วหน้าจอเล็ก | กดปุ่ม ⛶ บนแถบด้านบนเพื่อเปิดในแท็บใหม่แบบเต็มหน้าจอ (ต้องเผยแพร่เว็บแอปก่อน) |
| กราฟไม่แสดง | ระบบโหลด Chart.js จากอินเทอร์เน็ต — ตรวจสอบการเชื่อมต่อ หรือรอสักครู่แล้วกด 🔄 |
| ส่งออกไฟล์ไม่สำเร็จ | ตรวจว่า `appsscript.json` มีสิทธิ์ `drive` และ `script.external_request` แล้ว deploy เวอร์ชันใหม่ |
| ส่งอีเมลไม่ได้ | โควตา MailApp ของบัญชีทั่วไปคือ 100 ฉบับ/วัน (Workspace 1,500 ฉบับ/วัน) |
| ปุ่มดาวน์โหลดไม่ทำงาน | บางเบราว์เซอร์บล็อกการดาวน์โหลดในหน้าต่างซ้อน — กด **เปิดใน Drive** แทน หรือใช้ผ่านลิงก์เว็บแอป |
| ลืมรหัสผ่านผู้ดูแลระบบ | ดู [SECURITY.md](SECURITY.md) — มี 3 ช่องทางกู้คืน |
