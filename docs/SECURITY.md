# ความปลอดภัยและการกู้คืนรหัสผ่าน

## 1. การเก็บรหัสผ่าน

| | ระบบเดิม (v2) | ระบบใหม่ (v3) |
|---|---|---|
| อัลกอริทึม | SHA-256 รอบเดียว | SHA-256 วนซ้ำ 4,096 รอบ (key stretching) |
| salt | ค่าคงที่ตัวเดียวทั้งระบบ (`teacher_eval_salt_2024`) | สุ่มเฉพาะรายบุคคล 32 ตัวอักษร |
| ผลที่ตามมา | ทำตาราง rainbow table ครั้งเดียวถอดได้ทุกบัญชี | ต้องเจาะทีละบัญชี และช้าลงหลายพันเท่า |

- การเปรียบเทียบค่าแฮชใช้วิธี **constant-time** เพื่อไม่ให้เดารหัสผ่านจากเวลาที่ระบบตอบกลับ
- ระบบ **ไม่เคยส่งค่าแฮชหรือ salt ออกไปยังหน้าเว็บ**
- รหัสผ่านของระบบเดิมยังใช้เข้าสู่ระบบได้ และจะถูก **อัปเกรดเป็นรูปแบบใหม่อัตโนมัติ**
  ในการเข้าสู่ระบบครั้งถัดไป โดยผู้ใช้ไม่ต้องทำอะไร

### นโยบายรหัสผ่าน
- อย่างน้อย 8 ตัวอักษร ต้องมีทั้งตัวอักษรและตัวเลข
- ปฏิเสธรหัสผ่านที่คาดเดาง่าย (`password`, `admin123`, `123456`, ฯลฯ)
- รหัสผ่านที่ระบบสุ่มให้ผู้ประเมินจะผ่านนโยบายนี้เสมอ และถูกบังคับให้เปลี่ยนเมื่อเข้าใช้ครั้งแรก

## 2. การป้องกันการเดารหัสผ่าน

| กลไก | รายละเอียด |
|---|---|
| ล็อกรายบัญชี | ผู้ประเมินกรอกผิดครบจำนวนที่กำหนด (ค่าเริ่มต้น 5 ครั้ง) → ล็อก 15 นาที |
| ล็อกรายเครื่อง | ผู้ดูแลระบบกรอกผิดครบจำนวน → ล็อกเฉพาะเครื่องนั้น |
| เพดานรวมทั้งระบบ | ป้องกันการยิงรหัสจากหลายเครื่องพร้อมกัน โดยไม่ทำให้ผู้ใช้จริงถูกล็อกง่าย |
| ผู้ดูแลปลดล็อกได้ | หน้า "ผู้ประเมิน" มีปุ่มปลดล็อกบัญชีทันที |
| ข้อความผิดพลาดกลาง ๆ | ไม่บอกว่าผิดที่ชื่อผู้ใช้หรือรหัสผ่าน เพื่อไม่ให้เดาว่ามีบัญชีนี้อยู่จริงหรือไม่ |

ปรับค่าทั้งหมดได้ที่ **ตั้งค่าและความปลอดภัย**

---

## 3. เซสชัน

- เข้าสู่ระบบสำเร็จจะได้ **token สุ่ม 48 ตัวอักษร** เก็บฝั่งเซิร์ฟเวอร์ในรูปแบบที่ผ่านการแฮชแล้ว
- หมดอายุ 2 ชั้น: **ไม่มีการใช้งาน 120 นาที** และ **อายุสูงสุด 8 ชั่วโมง** (ปรับได้)
- ทุกฟังก์ชันที่แตะข้อมูลจริงตรวจสอบ token และสิทธิ์ **ฝั่งเซิร์ฟเวอร์ทุกครั้ง**
  ไม่เชื่อข้อมูลที่ส่งมาจากหน้าเว็บ (เช่น ผู้ประเมินส่งรหัสครูที่ไม่มีสิทธิ์ประเมินมา ระบบจะปฏิเสธ)
- เปลี่ยนหรือกู้คืนรหัสผ่านผู้ดูแล → **เซสชันผู้ดูแลทุกเครื่องถูกเพิกถอนทันที**
- token เก็บใน `sessionStorage` ของเบราว์เซอร์ ปิดแท็บแล้วหาย

## 4. การกู้คืนรหัสผ่านผู้ดูแลระบบ (ลืมรหัสผ่าน)

ระบบเดิมไม่มีทางออกเมื่อลืมรหัสผ่าน ระบบใหม่มี **3 ช่องทาง**

### ช่องทางที่ 1 — OTP ทางอีเมล (ผู้ดูแลระบบทำเองได้)
1. หน้าเข้าสู่ระบบ → แท็บ **🛡️ ผู้ดูแลระบบ** → กด **ลืมรหัสผ่าน?**
2. กด **ส่งรหัสยืนยันไปยังอีเมลกู้คืน**
3. เปิดอีเมล นำรหัส 6 หลักมากรอกพร้อมตั้งรหัสผ่านใหม่

**ข้อกำหนดด้านความปลอดภัย**
- OTP ส่งไปยัง **อีเมลกู้คืนที่ตั้งไว้ล่วงหน้าเท่านั้น** ผู้ขอไม่สามารถระบุอีเมลปลายทางเองได้
- อายุ 15 นาที ใช้ได้ครั้งเดียว กรอกผิดได้ไม่เกิน 5 ครั้ง
- ขอรหัสได้ไม่เกิน 3 ครั้ง/ชั่วโมงต่อเครื่อง และ 10 ครั้ง/ชั่วโมงทั้งระบบ
- อีเมลที่แสดงบนหน้าจอถูกปกปิดบางส่วน (เช่น `ad****@school.ac.th`)
- เมื่อตั้งรหัสผ่านใหม่สำเร็จ ระบบส่งอีเมลแจ้งเตือนไปยังอีเมลกู้คืนอีกฉบับ

> ⚠️ **ต้องตั้งอีเมลกู้คืนไว้ก่อน** จึงจะใช้ช่องทางนี้ได้
> ตั้งได้ที่หน้า **ตั้งค่าและความปลอดภัย** หรือเมนู **🆘 ลืมรหัสผ่านผู้ดูแลระบบ → 📧 ตั้งอีเมลกู้คืนรหัสผ่าน**

### ช่องทางที่ 2 — เมนูสำหรับเจ้าของไฟล์
ใช้เมื่อยังไม่ได้ตั้งอีเมลกู้คืน หรือเข้าอีเมลไม่ได้

1. เปิดไฟล์ Google Sheets ของระบบ
2. เมนู **🏫 ระบบประเมินผล → 🆘 ลืมรหัสผ่านผู้ดูแลระบบ → 🔑 รีเซ็ตรหัสผ่านผู้ดูแลระบบ**
3. ระบบสร้างรหัสผ่านใหม่และแสดงบนหน้าจอทันที

ระบบตรวจสอบว่าผู้ใช้เป็น **เจ้าของไฟล์ Google Sheets** เท่านั้น
ผู้ที่ถูกแชร์ไฟล์แบบแก้ไขได้แต่ไม่ใช่เจ้าของจะถูกปฏิเสธ และบันทึกความพยายามนั้นไว้ในประวัติการใช้งาน

### ช่องทางที่ 3 — รันฟังก์ชันฉุกเฉินจากตัวแก้ไขสคริปต์
ใช้เมื่อเปิดเมนูไม่ได้ (เช่น สคริปต์มีปัญหา)

1. **ส่วนขยาย → Apps Script**
2. เลือกฟังก์ชัน **`emergencyResetAdminPassword`** จากรายการด้านบน → กด **Run**
3. อ่านรหัสผ่านใหม่ได้ที่ **Execution log**

ช่องทางนี้ใช้ได้เฉพาะผู้ที่มีสิทธิ์แก้ไขสคริปต์ ซึ่งเป็นสิทธิ์ระดับเดียวกับเจ้าของระบบอยู่แล้ว

> ทุกช่องทางจะ **บันทึกลงประวัติการใช้งาน** และ **เพิกถอนเซสชันผู้ดูแลทั้งหมด** เสมอ

## 5. การป้องกันข้อมูลรั่วไหลและการโจมตีหน้าเว็บ

- ข้อมูลจากผู้ใช้ทุกจุดถูก **escape ก่อนแสดงผล** (กัน XSS จากชื่อครู/ข้อเสนอแนะ)
- ชีท `ตั้งค่าระบบ` และ `ผู้ประเมิน` ถูก **ซ่อนและตั้งการป้องกัน** ไว้
- คอลัมน์แฮชรหัสผ่านถูกซ่อนในชีท
- API ทุกตัวคืนค่าเฉพาะข้อมูลที่จำเป็น ไม่ส่งค่าแฮช/salt/token ของผู้อื่น
- ปิดการแสดงรายชื่อผู้ประเมินในหน้าเข้าสู่ระบบได้ (ตั้งค่า → ผู้ประเมินต้องพิมพ์ชื่อเอง)
- จำกัดบัญชี Google ที่เข้าสู่ระบบผู้ดูแลได้ (ตั้งค่า → "จำกัดบัญชี Google...")
- การเขียนข้อมูลทุกครั้งใช้ **LockService** ป้องกันข้อมูลชนกันเมื่อมีผู้ใช้พร้อมกัน

---

## 6. การตรวจสอบย้อนหลัง

ชีท `ประวัติการใช้งาน` บันทึกทุกเหตุการณ์สำคัญ: เข้า/ออกจากระบบ (สำเร็จและไม่สำเร็จ),
เพิ่ม/แก้ไข/ลบข้อมูล, รีเซ็ตรหัสผ่าน, ส่งออกรายงาน, จัดเก็บและกู้คืนข้อมูล
พร้อมวันเวลา ชื่อผู้ใช้ บทบาท และบัญชี Google ที่ใช้งาน

ผลการประเมินไม่ถูกลบถาวร — ทุกฉบับที่ถูกแก้ไขหรือลบจะถูกเก็บไว้ในชีท `คลังผลการประเมิน`

## 7. ข้อควรระวังที่เหลืออยู่

| เรื่อง | คำอธิบาย |
|---|---|
| สิทธิ์ไฟล์ Google Sheets | ผู้ที่ถูกแชร์ไฟล์แบบ **แก้ไขได้** สามารถเปิดชีทที่ซ่อนไว้และแก้ข้อมูลตรง ๆ ได้ **แชร์ไฟล์เฉพาะผู้ดูแลระบบเท่านั้น** ผู้ประเมินให้ใช้ลิงก์เว็บแอป |
| การเผยแพร่แบบ Anyone | เว็บแอปเปิดให้ทุกคนเข้าถึงหน้าเข้าสู่ระบบได้ แต่ข้อมูลทุกอย่างต้องผ่านการยืนยันตัวตนของระบบ หากใช้ Google Workspace แนะนำให้จำกัดเป็นเฉพาะในองค์กร |
| โควตาอีเมล | บัญชี Google ทั่วไปส่งได้ 100 ฉบับ/วัน — หากส่งรหัสผ่านจำนวนมากอาจถึงโควตา |
| อีเมลกู้คืน | ควรใช้อีเมลที่ปลอดภัยและเข้าถึงได้เสมอ เพราะเป็นกุญแจสำรองของระบบ |
