# ประวัติการเปลี่ยนแปลง

## v3.2.0

### นำเข้ารายชื่อครูจากไฟล์
- อัปโหลดไฟล์ **Excel (.xlsx .xls .ods)** และ **CSV / TSV** ได้โดยตรง (ลากไฟล์มาวางได้)
- มี **เทมเพลตให้ดาวน์โหลด** ทั้งแบบ Excel (พร้อมตัวเลือกแบบเลื่อนลงและแผ่นคำแนะนำ)
  และแบบ CSV (ใส่ BOM ให้ Excel เปิดภาษาไทยได้ถูกต้อง)
- จับคู่คอลัมน์จากหัวตารางอัตโนมัติ รองรับชื่อคอลัมน์หลายแบบ เช่น "ระดับชั้น" / "ชั้น" / "level"
  และรองรับไฟล์ที่มีเฉพาะคอลัมน์ "ชื่อ-นามสกุล" (ระบบแยกคำนำหน้าให้เอง)
- ไฟล์ที่ไม่มีหัวตารางก็อ่านได้ โดยใช้ลำดับคอลัมน์มาตรฐาน
- อ่านไฟล์ CSV ภาษาไทยที่บันทึกจาก Excel แบบเดิม (TIS-620/Windows-874) ได้
- **ตรวจสอบและแสดงตัวอย่างก่อนบันทึกจริง** แยกสถานะรายแถวเป็น เพิ่มใหม่ / อัปเดต / ข้าม / ผิดพลาด
- เลือกได้ว่าจะ "อัปเดตข้อมูลเดิม" เมื่อพบชื่อหรือรหัสครูซ้ำ
- ยังคงนำเข้าด้วยการวางข้อความจาก Excel ได้เหมือนเดิม

### คะแนนสุทธิแบบถ่วงน้ำหนักตามกลุ่มผู้ประเมิน
- เมนูใหม่ **"⚖️ น้ำหนักผู้ประเมิน"** กำหนดได้ว่าคะแนนจากผู้ประเมินแต่ละกลุ่ม
  (รอง ผอ. / หัวหน้ากลุ่มกิจการนักเรียน / หัวหน้าระดับชั้น / หัวหน้าเวรประจำวัน)
  จะคิดเป็นกี่ % ของคะแนนรวม
- สูตร: **คะแนนสุทธิ = Σ (คะแนนเฉลี่ยของกลุ่ม × น้ำหนักของกลุ่ม) ÷ Σ น้ำหนักที่ใช้จริง**
- ตัวเลือก **ปรับสัดส่วนอัตโนมัติ** เมื่อครูไม่ได้รับการประเมินจากบางกลุ่ม
  เพื่อไม่ให้เสียเปรียบ (เปิดไว้เป็นค่าเริ่มต้น)
- **ดูผลกระทบก่อนบันทึกได้** — เทียบคะแนนและอันดับก่อน-หลัง พร้อมลูกศรบอกอันดับที่เปลี่ยน
- แถบสัดส่วนและสูตรแสดงสดขณะปรับน้ำหนัก
- คะแนนสุทธิถูกใช้ในแดชบอร์ด การจัดอันดับ การเรียงลำดับก่อนส่งออก และรายงาน
- รายงานที่ส่งออกเพิ่มคอลัมน์ "คะแนนสุทธิ" และแผ่นงาน **"วิธีคิดคะแนนสุทธิ"**
  ที่แสดงน้ำหนักและตัวอย่างการคำนวณ เพื่อให้ตรวจสอบที่มาของคะแนนได้
- ค่าเฉลี่ยรวมแบบเดิมยังถูกเก็บและแสดงคู่กันเสมอ

### แก้ไข
- คำนำหน้า "นางสาว" ถูกตัดเหลือ "นาง" เมื่อแยกชื่อเต็ม (เกิดทั้งตอนแก้ไขข้อมูลครูและตอนนำเข้า)

## v3.1.0

### เพิ่มใหม่
- **เมนู "ปีการศึกษาและภาคเรียน"** — ตั้งค่าได้อย่างอิสระ
  - เลือกปีการศึกษาปัจจุบันและภาคเรียนปัจจุบันแยกจากกัน
  - เพิ่ม/ลบปีการศึกษาในรายการที่เปิดใช้งาน (ไม่กระทบข้อมูลการประเมิน)
  - เปิด/ปิดภาคเรียนได้ตามที่ใช้จริง **รองรับภาคฤดูร้อน**
  - ตารางสรุปจำนวนข้อมูลของทุกภาคเรียนในหน้าเดียว พร้อมปุ่มลัด
- **เมนู "เคลียร์ข้อมูลการประเมิน"** — ล้างข้อมูลรายภาคเรียน รายปีการศึกษา หรือทั้งหมด
  - เลือกได้ว่าจะย้ายเข้าคลัง (กู้คืนได้) หรือลบถาวร
  - เลือกขอบเขตได้ทั้งตารางหลัก คลังข้อมูล หรือทั้งสองส่วน
  - สำรองเป็นไฟล์ Excel เก็บใน Google Drive ก่อนลบได้
  - ต้องพิมพ์ข้อความยืนยันให้ตรงก่อนดำเนินการ และบันทึกลงประวัติการใช้งานทุกครั้ง

### ความเร็ว (ดูรายละเอียดใน docs/PERFORMANCE.md)
- ลดจำนวนครั้งที่ต้องคุยกับ Google Sheets ลง **33%** เมื่อแคชว่าง และ **76%** ในการใช้งานปกติ
- จำผลการอ่านภายในงานเดียวกัน และแคชร่วมข้ามผู้ใช้สำหรับตารางที่เปลี่ยนไม่บ่อย
  (ตารางผลการประเมินไม่ถูกแคช เพื่อให้เห็นข้อมูลล่าสุดเสมอ)
- เขียนข้อมูลเป็นช่วงเดียวแทนการเขียนทีละช่อง — บันทึกผลการประเมินเร็วขึ้นประมาณ 3.6 เท่า
- ลบหลายแถวเป็นชุด, หารหัสถัดไปจากแถวสุดท้าย, อ่านประวัติเฉพาะรายการล่าสุด
- ฝั่งหน้าจอ: แคชผลลัพธ์ 45 วินาที, โหลดไลบรารีกราฟเมื่อจำเป็นเท่านั้น, ปิดภาพเคลื่อนไหวกราฟบนมือถือ

### หน้าจอ
- **เต็มหน้าจอทุกอุปกรณ์** — เลื่อนเฉพาะส่วนเนื้อหา ไม่มีแถบเลื่อนซ้อนกัน
- เมนูปรับตามขนาดจอ: เมนูเต็ม (คอมพิวเตอร์) → แถบไอคอนพร้อมป้ายชื่อ (แท็บเล็ต) →
  ลิ้นชัก + แถบเมนูล่าง (มือถือ)
- ตารางข้อมูลแสดงเป็นการ์ดอัตโนมัติบนจอแคบ อ่านง่ายโดยไม่ต้องเลื่อนซ้าย-ขวา
- ขนาดตัวอักษรและระยะห่างปรับตามความกว้างจอ, ปุ่มมีขนาดพอสำหรับกดด้วยนิ้ว (44px),
  รองรับจอมีติ่ง (safe area) และ `100dvh` บนมือถือ
- เพิ่มปุ่มโหลดข้อมูลใหม่ 🔄 และปุ่มเต็มหน้าจอ ⛶
- ปรับสีระดับผลการประเมินให้อ่านชัดในโหมดมืด

### แก้ไข
- ปุ่มเปิดเมนู ☰ แสดงบนจอใหญ่โดยไม่ตั้งใจ (กฎ CSS ของ `.btn` ทับ `.menu-toggle`)
- ตารางความหมายคะแนนในชีทเกณฑ์ถูกอ่านปนเป็นเกณฑ์การประเมิน
- ชื่อภาคเรียนแสดงไม่ตรงกันในบางหน้า รวมศูนย์เป็นฟังก์ชันเดียว

## v3.0.0

### เพิ่มใหม่
- **เว็บแอปหน้าเดียว** ใช้งานได้ทั้งบนคอมพิวเตอร์และมือถือ พร้อมโหมดสว่าง/มืด
  แทนที่หน้าต่างซ้อนแยก 4 หน้าของระบบเดิม
- **ส่งออกรายงาน Excel (.xlsx) และ PDF** พร้อมหัวรายงาน ช่องลงนาม
  และแผ่นงานเสริม (คะแนนรายข้อ / ข้อเสนอแนะ / รายการประเมินทั้งหมด)
- **เลือกและจัดลำดับผู้ถูกประเมินก่อนประมวลผล** — ลากสลับตำแหน่ง ปุ่มเลื่อนขึ้น-ลง
  และการเรียงอัตโนมัติ 5 รูปแบบ พร้อมหน้าดูตัวอย่างก่อนส่งออก
- **ตารางเวรประจำวันแยกอิสระตามภาคเรียน** เก็บบทบาทในเวร จุดปฏิบัติหน้าที่ เวลา
  และระดับชั้นที่ดูแล พร้อมฟังก์ชันคัดลอกข้ามภาคเรียนและสร้างจากค่าเริ่มต้น
- **คลังข้อมูลการประเมินย้อนหลัง** เก็บทุกฉบับที่ถูกแก้ไข ลบ หรือปิดภาคเรียน
  ค้นหาและกู้คืนได้ พร้อมหน้าดูพัฒนาการของครูรายคนข้ามภาคเรียน
- **ระบบกู้คืนรหัสผ่านผู้ดูแลระบบ 3 ช่องทาง** — OTP ทางอีเมล, เมนูสำหรับเจ้าของไฟล์,
  ฟังก์ชันฉุกเฉินจากตัวแก้ไขสคริปต์
- **จัดการเกณฑ์การประเมินจากหน้าจอ** เพิ่ม/แก้ไข/ปิดใช้/ตั้งน้ำหนัก รองรับสูงสุด 20 ข้อ
- จัดการทะเบียนครูจากหน้าจอ พร้อมนำเข้ารายชื่อจาก Excel
- ส่งรหัสผ่านให้ผู้ประเมินทางอีเมลอัตโนมัติ
- แดชบอร์ดแสดงความคืบหน้าการประเมินรายบุคคล
- หน้าประวัติการใช้งาน (audit log) และเมนูตรวจสุขภาพระบบ
- ชุดทดสอบอัตโนมัติ 125 รายการ (`tests/run-all.sh`) และฟังก์ชัน `runSelfTest()` ในระบบ

### ความปลอดภัย
- เปลี่ยนการเก็บรหัสผ่านจาก SHA-256 รอบเดียว + salt ร่วม
  เป็น **salt เฉพาะราย + วนแฮช 4,096 รอบ** (อัปเกรดรหัสผ่านเดิมอัตโนมัติ)
- เปรียบเทียบค่าแฮชแบบ constant-time
- ล็อกบัญชีเมื่อกรอกรหัสผ่านผิดเกินกำหนด ทั้งรายบัญชี รายเครื่อง และเพดานรวมทั้งระบบ
- เซสชันมี token, หมดอายุตามเวลาไม่ใช้งานและอายุสูงสุด, เพิกถอนได้เมื่อเปลี่ยนรหัสผ่าน
- ตรวจสอบสิทธิ์ฝั่งเซิร์ฟเวอร์ทุกครั้ง ไม่เชื่อข้อมูลจากหน้าเว็บ
- นโยบายรหัสผ่านขั้นต่ำ และบังคับเปลี่ยนรหัสผ่านครั้งแรก
- escape ข้อมูลผู้ใช้ทุกจุดก่อนแสดงผล (กัน XSS)
- ซ่อนและป้องกันชีทที่มีข้อมูลอ่อนไหว จำกัดบัญชี Google ที่เข้าระบบผู้ดูแลได้
- ใช้ LockService ป้องกันข้อมูลชนกันเมื่อมีผู้ใช้พร้อมกัน

### แก้ไขข้อบกพร่องของระบบเดิม
- **คะแนนเก็บเป็นสูตรในชีท** ทำให้ค่าพังเมื่อย้าย/ลบแถว → เปลี่ยนเป็นคำนวณและเก็บค่าคงที่
- **ประเมินซ้ำได้ไม่จำกัด** ทำให้สรุปผลคลาดเคลื่อน → หนึ่งผู้ประเมินต่อครูต่อภาคเรียนมีผลเดียว
  การบันทึกทับจะเก็บฉบับเดิมไว้ในคลัง
- **การลบผลการประเมินหายถาวร** → ย้ายเข้าคลังข้อมูลแทน
- **อ้างอิงข้อมูลด้วยชื่อ-นามสกุล** ทำให้ข้อมูลขาดเมื่อแก้ชื่อ → เพิ่มรหัสอ้างอิงถาวรและ
  ปรับชื่อให้ตรงกันทั้งระบบเมื่อมีการแก้ไข
- **`showPage()` พึ่งพาตัวแปร `event` ส่วนกลาง** → เขียนระบบเมนูใหม่ทั้งหมด
- **ลบผลการประเมินโดยส่งเลขแถว** เสี่ยงลบผิดแถวเมื่อข้อมูลเปลี่ยน → ใช้รหัสการประเมินแทน
- **ไม่ตรวจสอบสิทธิ์ก่อนบันทึก** → ตรวจสอบสิทธิ์และความถูกต้องของคะแนนฝั่งเซิร์ฟเวอร์
- **แสดงผลด้วยการต่อสตริง HTML จากข้อมูลผู้ใช้** → escape ทุกจุด
- **เวรประจำวันมีค่าเดียวต่อครู** ทำให้ข้อมูลย้อนหลังเปลี่ยนตามเมื่อสลับเวร →
  แยกตารางเวรตามภาคเรียน
