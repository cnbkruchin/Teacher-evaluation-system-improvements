# คู่มือการใช้งาน

## เข้าใช้งานระบบ

| ผู้ใช้ | ช่องทาง |
|---|---|
| ผู้ดูแลระบบ | เปิดไฟล์ Google Sheets → เมนู **🏫 ระบบประเมินผล → 🚀 เปิดระบบ** หรือใช้ลิงก์เว็บแอปก็ได้ |
| ผู้ประเมิน | เปิด **ลิงก์เว็บแอป** ที่ผู้ดูแลระบบส่งให้ (ใช้ได้บนมือถือ) |

หน้าเข้าสู่ระบบมี 2 แท็บ: **📝 ผู้ประเมิน** และ **🛡️ ผู้ดูแลระบบ**
ปุ่ม **🌓 สลับโหมดสี** เปลี่ยนระหว่างโหมดสว่าง/มืดได้ทุกหน้า

# ส่วนของผู้ประเมิน

## 1. แบบประเมิน
1. เลือก **ปีการศึกษา / ภาคเรียน** (ค่าเริ่มต้นคือภาคเรียนปัจจุบัน)
2. เลือกครูจากรายการ — ค้นหาด้วยการพิมพ์ชื่อได้ ครูที่ประเมินแล้วจะมีเครื่องหมาย ✅
3. ระบบแสดงข้อมูลครูและ **เวรประจำวันของภาคเรียนนั้น** ให้ประกอบการพิจารณา
4. ให้คะแนน 1–5 ทุกข้อ (มีปุ่มลัด "ให้ 5 ทุกข้อ" แล้วปรับเฉพาะข้อที่ต้องการ)
5. กรอกข้อเสนอแนะ (ถ้ามี) แล้วกด **✅ บันทึกผลการประเมิน**

> ปุ่มบันทึกจะกดได้เมื่อให้คะแนนครบทุกข้อ — ดูความคืบหน้าได้ที่มุมขวาบนของกล่องเกณฑ์

**เห็นครูไม่ครบ / ไม่เห็นครูเลย?** ระบบแสดงเฉพาะครูที่ท่านมีสิทธิ์ประเมิน
- รอง ผอ. และหัวหน้ากลุ่มบริหารงานกิจการนักเรียน → ครูทุกคน
- หัวหน้าระดับชั้น → ครูในระดับชั้นที่รับผิดชอบ
- หัวหน้าเวรประจำวัน → ครูที่อยู่เวรวันเดียวกัน **ตามตารางเวรของภาคเรียนที่เลือก**

## 2. แก้ไขผลที่เคยบันทึก
เลือกครูคนเดิมอีกครั้ง ระบบจะดึงคะแนนเดิมขึ้นมาให้แก้ไข
เมื่อบันทึกทับ **ฉบับเดิมจะถูกเก็บไว้ในคลังข้อมูล** เพื่อตรวจสอบย้อนหลังได้

## 3. เมนูอื่น ๆ
- **📋 ผลที่ฉันประเมินแล้ว** — รายการทั้งหมดที่บันทึกไว้ กดดูคะแนนรายข้อได้
- **📅 ตารางเวรประจำวัน** — ตารางเวรของภาคเรียนที่เลือก แยกตามวัน
- **🔑 เปลี่ยนรหัสผ่าน** — ควรเปลี่ยนทันทีหลังได้รับรหัสจากผู้ดูแลระบบ

# ส่วนของผู้ดูแลระบบ

## 📊 แดชบอร์ด
- สถิติภาพรวม: จำนวนการประเมิน ครูที่ถูกประเมิน คะแนนเฉลี่ยรวม จำนวนครูระดับดีเยี่ยม
- กราฟ 4 ชุด: การกระจายระดับผล, คะแนนตามระดับชั้น, คะแนนตามเวรประจำวัน, สัดส่วนตามบทบาทผู้ประเมิน
- **ความคืบหน้าของผู้ประเมิน** — ใครประเมินไปแล้วกี่คนจากทั้งหมด (เรียงจากน้อยไปมาก เพื่อติดตามได้ง่าย)
- อันดับคะแนนสูงสุด และรายชื่อที่ควรได้รับการพัฒนา
- กรองตามปีการศึกษา/ภาคเรียนได้ หรือเลือก "ทุกปี/ทุกภาคเรียน"

## 📋 ผลการประเมิน
ค้นหาและกรองตามปีการศึกษา ภาคเรียน ระดับชั้น วันเวร หรือชื่อครู/ผู้ประเมิน
- **ดู** — คะแนนรายข้อ ข้อเสนอแนะ และ **ประวัติฉบับก่อนหน้า** (ถ้ามีการแก้ไข)
- **ลบ** — ย้ายเข้าคลังข้อมูล (ไม่ลบถาวร กู้คืนได้)

## 📤 ประมวลผลและส่งออก

**ขั้นที่ 1 — เลือกภาคเรียน**
เลือกปีการศึกษาและภาคเรียน แล้วกด "โหลดข้อมูลภาคเรียนนี้"
ติ๊ก **"รวมข้อมูลจากคลังย้อนหลังด้วย"** หากภาคเรียนนั้นถูกปิดและจัดเก็บไปแล้ว

**ขั้นที่ 2 — เลือกและจัดลำดับผู้ถูกประเมิน**
- คอลัมน์ซ้ายคือรายชื่อทั้งหมด กรองด้วยการค้นหา ระดับชั้น หรือวันเวร
  ปุ่มลัด: **เลือกทั้งหมด** / **เฉพาะที่ประเมินแล้ว**
- คอลัมน์ขวาคือรายการที่จะส่งออก จัดลำดับได้ 2 วิธี
  - **ลากสลับตำแหน่ง** (จับที่สัญลักษณ์ ⠿) หรือกดปุ่ม ▲ ▼
  - เลือก **การเรียงอัตโนมัติ**: ตามชื่อ, คะแนนมาก→น้อย, คะแนนน้อย→มาก, ระดับชั้น, เวรประจำวัน
- ลำดับที่เห็นบนหน้าจอ คือลำดับที่จะปรากฏในรายงาน

**ขั้นที่ 3 — ตั้งค่าและประมวลผล**
- ตั้งชื่อรายงาน หมายเหตุ และแนวกระดาษของ PDF
- เลือกแผ่นงานที่ต้องการ: คะแนนรายข้อ / ข้อเสนอแนะ / รายการประเมินทั้งหมด
- **👁️ ประมวลผล / ดูตัวอย่าง** — ตรวจสอบผลก่อนส่งออกจริง
- **📊 ส่งออก Excel** / **📄 ส่งออก PDF** / **📦 ทั้งสองรูปแบบ**
- **📑 สรุปลงชีทในไฟล์นี้** — เขียนผลสรุปลงชีท "สรุปผลการประเมิน"

ไฟล์ที่ได้จะถูกเก็บใน Google Drive โฟลเดอร์ **"รายงานผลการประเมินครู"**
และมีปุ่มดาวน์โหลดทันที (หากเบราว์เซอร์บล็อก ให้กด "เปิดใน Drive")

## 🗄️ คลังข้อมูลย้อนหลัง
- **ปิดภาคเรียน** — ย้ายผลการประเมินของภาคเรียนนั้นทั้งหมดเข้าคลัง
  เพื่อเริ่มภาคเรียนใหม่ด้วยตารางที่สะอาด โดยยังนำข้อมูลเดิมมาออกรายงานได้
- **ค้นหา** ตามปีการศึกษา ภาคเรียน ประเภทการจัดเก็บ หรือชื่อ
- **กู้คืน** — ติ๊กเลือกรายการแล้วกด "↩️ กู้คืนที่เลือก" เพื่อนำกลับสู่ตารางหลัก

ประเภทการจัดเก็บมี 3 แบบ: `ฉบับแก้ไข` (ผู้ประเมินบันทึกทับ), `ลบโดยผู้ดูแลระบบ`, `จัดเก็บภาคเรียน`

## 🧑‍🏫 ครูผู้รับการประเมิน
- เพิ่ม/แก้ไขทีละคน หรือ **📥 นำเข้ารายชื่อ** โดยวางข้อมูลจาก Excel
  (คำนำหน้า | ชื่อ | นามสกุล | ระดับชั้น | เวรประจำวัน | อีเมล)
- **ประวัติ** — ดูคะแนนของครูรายคนข้ามภาคเรียน เพื่อดูพัฒนาการ
- ครูที่มีผลการประเมินแล้วจะลบไม่ได้ ให้เปลี่ยนสถานะเป็น "ไม่ใช้งาน" แทน เพื่อรักษาข้อมูลย้อนหลัง

## 👥 ผู้ประเมิน
- เพิ่มผู้ประเมิน → ระบบสุ่มรหัสผ่านให้ **แสดงครั้งเดียว** (และส่งอีเมลอัตโนมัติหากกรอกอีเมลไว้)
- **🔑 รีเซ็ต** — ออกรหัสผ่านใหม่, **ปิดใช้/เปิดใช้** — ระงับการเข้าใช้ชั่วคราว
- **ปลดล็อก** — ปรากฏเมื่อบัญชีถูกล็อกจากการกรอกรหัสผ่านผิดหลายครั้ง
- คอลัมน์ "ครูที่รับผิดชอบ" ช่วยตรวจว่าตั้งขอบเขตถูกต้องหรือไม่ (ถ้าเป็น 0 แปลว่ายังไม่มีครูในขอบเขตนั้น)

## 📅 เวรประจำวันรายภาคเรียน
**ตารางเวรของแต่ละภาคเรียนแยกจากกันอย่างสมบูรณ์** — แก้ไขเวรของภาคเรียนใหม่
ได้โดยไม่กระทบข้อมูลและผลการประเมินของภาคเรียนก่อนหน้า

- **🪄 สร้างจากค่าเริ่มต้นในทะเบียนครู** — สร้างตารางเวรทั้งหมดในคลิกเดียว
- **📋 คัดลอกจากภาคเรียนอื่น** — เริ่มภาคเรียนใหม่จากของเดิมแล้วค่อยปรับ
- **➕ เพิ่มรายการเวร** — ระบุวัน บทบาทในเวร (หัวหน้าเวร/รองหัวหน้าเวร/กรรมการเวร)
  จุดปฏิบัติหน้าที่ เวลาเริ่ม-สิ้นสุด ระดับชั้นที่ดูแล และหมายเหตุ
- ส่วน "ครูที่ยังไม่มีเวรในภาคเรียนนี้" กดชื่อเพื่อเพิ่มได้ทันที

> การเปลี่ยนวันเวรมีผลต่อสิทธิ์ของ "หัวหน้าเวรประจำวัน" ในภาคเรียนนั้นทันที

## 📝 เกณฑ์การประเมิน
แก้ไขชื่อเกณฑ์ กำหนดผู้มีสิทธิ์ประเมินแต่ละข้อ ตั้งน้ำหนัก และเปิด/ปิดการใช้งานได้
รองรับสูงสุด 20 ข้อ (ค่าเริ่มต้น 10 ข้อตามระบบเดิม)
เปิดโหมด **คิดคะแนนแบบถ่วงน้ำหนัก** ได้ที่หน้าตั้งค่า

## ⚙️ ตั้งค่าและความปลอดภัย
- ปีการศึกษา/ภาคเรียนปัจจุบัน และรายการปีที่เปิดใช้งาน
- ข้อมูลสำหรับรายงาน: ชื่อสถานศึกษา ผู้ลงนาม ตำแหน่ง
- เกณฑ์ตัดระดับผลการประเมิน (ดีเยี่ยม/ดีมาก/ดี/พอใช้)
- **อีเมลกู้คืนรหัสผ่าน** พร้อมปุ่มทดสอบส่งอีเมล ← ควรตั้งไว้เสมอ
- นโยบายความปลอดภัย: จำนวนครั้งที่กรอกผิดได้ ระยะเวลาล็อก อายุเซสชัน
- เปลี่ยนรหัสผ่านผู้ดูแลระบบ
- **🩺 สถานะระบบ** — ตรวจความพร้อมของทุกส่วน

## 🕘 ประวัติการใช้งาน
บันทึกทุกการเข้าสู่ระบบ การแก้ไขข้อมูล และการส่งออกรายงาน พร้อมช่องกรองข้อความ

## รอบการทำงานที่แนะนำในแต่ละภาคเรียน

1. **ต้นภาคเรียน** — ตั้งปีการศึกษา/ภาคเรียนปัจจุบัน → คัดลอกหรือสร้างตารางเวรของภาคเรียนใหม่
   → ตรวจทะเบียนครูและผู้ประเมินให้เป็นปัจจุบัน
2. **ระหว่างภาคเรียน** — ผู้ประเมินเข้าประเมินผ่านลิงก์เว็บแอป
   ผู้ดูแลติดตามที่แดชบอร์ด → "ความคืบหน้าของผู้ประเมิน"
3. **ปลายภาคเรียน** — ประมวลผลและส่งออก Excel/PDF เสนอผู้บริหาร
4. **ปิดภาคเรียน** — ใช้ "📦 จัดเก็บภาคเรียนนี้" เพื่อย้ายข้อมูลเข้าคลัง แล้วเริ่มภาคเรียนถัดไป
