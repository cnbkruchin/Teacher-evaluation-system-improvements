# คู่มือการใช้งาน

## เข้าใช้งานระบบ

| ผู้ใช้ | ช่องทาง |
|---|---|
| ผู้ดูแลระบบ | เปิดไฟล์ Google Sheets → เมนู **🏫 ระบบประเมินผล → 🚀 เปิดระบบ** หรือใช้ลิงก์เว็บแอปก็ได้ |
| ผู้ประเมิน | เปิด **ลิงก์เว็บแอป** ที่ผู้ดูแลระบบส่งให้ (ใช้ได้บนมือถือ) |

หน้าเข้าสู่ระบบมี 2 แท็บ: **📝 ผู้ประเมิน** และ **🛡️ ผู้ดูแลระบบ**

**ปุ่มบนแถบด้านบน**

| ปุ่ม | หน้าที่ |
|---|---|
| ☰ | เปิดเมนู (แสดงเฉพาะบนมือถือ/แท็บเล็ตแนวตั้ง) |
| 🔄 | โหลดข้อมูลใหม่ล่าสุดจากเซิร์ฟเวอร์ |
| ⛶ | ขยายเต็มหน้าจอ (ถ้าเปิดจากหน้าต่างซ้อนใน Google Sheets จะเปิดในแท็บใหม่แทน) |
| 🌓 | สลับโหมดสว่าง/มืด |
| 🚪 | ออกจากระบบ |

**การแสดงผลตามอุปกรณ์**
- **คอมพิวเตอร์** — เมนูข้างแบบเต็ม เห็นทุกเมนูพร้อมกัน
- **แท็บเล็ต** — เมนูย่อเป็นแถบไอคอน ชี้ค้างเพื่อดูชื่อเมนู
- **มือถือ** — เมนูเป็นลิ้นชัก (กด ☰) พร้อมแถบเมนูล่างสำหรับเมนูที่ใช้บ่อย
  และตารางข้อมูลจะแสดงเป็นการ์ดแทนการเลื่อนซ้าย-ขวา

# ส่วนของผู้ประเมิน

## 1. แบบประเมิน
1. เลือก **ชุดประเมิน** (แสดงเมื่อท่านได้รับมอบหมายมากกว่า 1 ชุด) และ **ปีการศึกษา / ภาคเรียน**
2. เลือกครูจากรายการ — ค้นหาด้วยการพิมพ์ชื่อได้ ครูที่ประเมินแล้วจะมีเครื่องหมาย ✅
3. ระบบแสดงข้อมูลครูและ **เวรประจำวันของภาคเรียนนั้น** ให้ประกอบการพิจารณา
4. ให้คะแนนทุกข้อตามมาตราของชุดนั้น (ปกติ 1–5 · บางชุดอาจกำหนดเป็น 1–4 หรืออื่น ๆ)
   มีปุ่มลัดให้คะแนนเต็มทุกข้อแล้วปรับเฉพาะข้อที่ต้องการ
5. กรอกข้อเสนอแนะ (ถ้ามี) แล้วกด **✅ บันทึกผลการประเมิน**

> ปุ่มบันทึกจะกดได้เมื่อให้คะแนนครบทุกข้อ — ดูความคืบหน้าได้ที่มุมขวาบนของกล่องเกณฑ์

**ชุดประเมินคืออะไร?** โรงเรียนอาจแบ่งการประเมินเป็นหลายชุด เช่น ชุดงานกิจการนักเรียน
และชุดงานวิชาการ แต่ละชุดมีเกณฑ์และมาตราคะแนนของตัวเอง และคิดคะแนนแยกกัน
กล่องข้อมูลใต้ตัวเลือกจะบอกว่าท่านกำลังประเมินชุดใด อยู่ในกลุ่มผู้ประเมินกลุ่มใด
และชุดนั้นคิดเป็นกี่คะแนนของหน่วยงาน

**บันทึกไม่ได้ / ปุ่มเป็นสีเทา?** อาจอยู่นอกช่วงเวลาที่เปิดให้ประเมิน หรือภาคเรียนนั้นถูกล็อกแล้ว
ระบบจะแจ้งเหตุผลไว้ด้านบนของหน้าจอ — ติดต่อผู้ดูแลระบบเพื่อเปิดรอบการประเมินอีกครั้ง

**เห็นครูไม่ครบ / ไม่เห็นครูเลย?** ระบบแสดงเฉพาะครูที่ท่านมีสิทธิ์ประเมิน
- รอง ผอ. และหัวหน้ากลุ่มบริหารงานกิจการนักเรียน → ครูทุกคน
- หัวหน้าระดับชั้น → ครูในระดับชั้นที่รับผิดชอบ
- หัวหน้าเวรประจำวัน → ครูที่อยู่เวรวันเดียวกัน **ตามตารางเวรของภาคเรียนที่เลือก**

## 2. แก้ไขผลที่เคยบันทึก
เลือกครูคนเดิมอีกครั้ง ระบบจะดึงคะแนนเดิมขึ้นมาให้แก้ไข
เมื่อบันทึกทับ **ฉบับเดิมจะถูกเก็บไว้ในคลังข้อมูล** เพื่อตรวจสอบย้อนหลังได้

## 3. เมนูอื่น ๆ
- **📋 ผลที่ฉันประเมินแล้ว** — รายการทั้งหมดที่บันทึกไว้ กดดูคะแนนรายข้อได้
- **📅 ตารางเวรประจำวัน** — ตารางเวรของภาคเรียนที่เลือก แยกตามวัน
- **🔑 เปลี่ยนรหัสผ่าน** — ควรเปลี่ยนทันทีหลังได้รับรหัสจากผู้ดูแลระบบ

# ส่วนของผู้ดูแลระบบ

## 📊 แดชบอร์ด
- สถิติภาพรวม: จำนวนการประเมิน ครูที่ถูกประเมิน คะแนนเฉลี่ยรวม จำนวนครูระดับดีเยี่ยม
- กราฟ 4 ชุด: การกระจายระดับผล, คะแนนตามระดับชั้น, คะแนนตามเวรประจำวัน, สัดส่วนตามบทบาทผู้ประเมิน
- **ความคืบหน้าของผู้ประเมิน** — ใครประเมินไปแล้วกี่คนจากทั้งหมด (เรียงจากน้อยไปมาก เพื่อติดตามได้ง่าย)
- อันดับคะแนนสูงสุด และรายชื่อที่ควรได้รับการพัฒนา
- กรองตามปีการศึกษา/ภาคเรียนได้ หรือเลือก "ทุกปี/ทุกภาคเรียน"

## 📋 ผลการประเมิน
ค้นหาและกรองตามปีการศึกษา ภาคเรียน ระดับชั้น วันเวร หรือชื่อครู/ผู้ประเมิน
- **ดู** — คะแนนรายข้อ ข้อเสนอแนะ และ **ประวัติฉบับก่อนหน้า** (ถ้ามีการแก้ไข)
- **ลบ** — ย้ายเข้าคลังข้อมูล (ไม่ลบถาวร กู้คืนได้)

## 📤 ประมวลผลและส่งออก

**ขั้นที่ 1 — เลือกภาคเรียน**
เลือกปีการศึกษาและภาคเรียน แล้วกด "โหลดข้อมูลภาคเรียนนี้"
ติ๊ก **"รวมข้อมูลจากคลังย้อนหลังด้วย"** หากภาคเรียนนั้นถูกปิดและจัดเก็บไปแล้ว

**ขั้นที่ 2 — เลือกและจัดลำดับผู้ถูกประเมิน**
- คอลัมน์ซ้ายคือรายชื่อทั้งหมด กรองด้วยการค้นหา ระดับชั้น หรือวันเวร
  ปุ่มลัด: **เลือกทั้งหมด** / **เฉพาะที่ประเมินแล้ว**
- คอลัมน์ขวาคือรายการที่จะส่งออก จัดลำดับได้ 2 วิธี
  - **ลากสลับตำแหน่ง** (จับที่สัญลักษณ์ ⠿) หรือกดปุ่ม ▲ ▼
  - เลือก **การเรียงอัตโนมัติ**: ตามชื่อ, คะแนนมาก→น้อย, คะแนนน้อย→มาก, ระดับชั้น, เวรประจำวัน
- ลำดับที่เห็นบนหน้าจอ คือลำดับที่จะปรากฏในรายงาน

**ขั้นที่ 3 — ตั้งค่าและประมวลผล**
- ตั้งชื่อรายงาน หมายเหตุ และแนวกระดาษของ PDF
- เลือกแผ่นงานที่ต้องการ: คะแนนรายข้อ / ข้อเสนอแนะ / รายการประเมินทั้งหมด
- **👁️ ประมวลผล / ดูตัวอย่าง** — ตรวจสอบผลก่อนส่งออกจริง
- **📊 ส่งออก Excel** / **📄 ส่งออก PDF** / **📦 ทั้งสองรูปแบบ**
- **🪪 รายงานรายบุคคล** — ออกรายงานแบบ **หน้าละ 1 คน** พร้อมช่องลงนาม สำหรับแจ้งผลรายบุคคล
  (ครั้งละไม่เกิน 80 คน โรงเรียนที่มีครูมากกว่านี้ให้กรองทีละระดับชั้นหรือทีละวันเวร แล้วออกทีละรอบ)
- **📑 สรุปลงชีทในไฟล์นี้** — เขียนผลสรุปลงชีท "สรุปผลการประเมิน"

ไฟล์ที่ได้จะถูกเก็บใน Google Drive โฟลเดอร์ **"รายงานผลการประเมินครู"**
และมีปุ่มดาวน์โหลดทันที (หากเบราว์เซอร์บล็อก ให้กด "เปิดใน Drive")

**แผ่นงานที่อยู่ในไฟล์รายงาน**

| แผ่นงาน | เนื้อหา |
|---|---|
| สรุปผลการประเมิน | ตารางหลัก คะแนนรายกลุ่มผู้ประเมิน คะแนนสุทธิ คะแนนที่หน่วยงานได้รับ ระดับผล |
| คะแนนรายชุดประเมิน | ตารางครู × ชุดประเมิน คะแนนที่ได้รับของแต่ละชุด คะแนนรวม และร้อยละ |
| คะแนนรายข้อ | คะแนนเฉลี่ยรายข้อของครูทุกคน พร้อมคำอธิบายเลขข้อ |
| วิธีคิดคะแนนสุทธิ | น้ำหนักของแต่ละกลุ่ม และตัวอย่างการคำนวณจริง (เมื่อเปิดถ่วงน้ำหนัก) |
| ข้อเสนอแนะ | ข้อเสนอแนะทั้งหมดที่ผู้ประเมินเขียนไว้ |
| รายการประเมินทั้งหมด | ผลการประเมินดิบทุกรายการ ใช้ตรวจสอบย้อนหลัง |

## 🗄️ คลังข้อมูลย้อนหลัง
- **ปิดภาคเรียน** — ย้ายผลการประเมินของภาคเรียนนั้นทั้งหมดเข้าคลัง
  เพื่อเริ่มภาคเรียนใหม่ด้วยตารางที่สะอาด โดยยังนำข้อมูลเดิมมาออกรายงานได้
- **ค้นหา** ตามปีการศึกษา ภาคเรียน ประเภทการจัดเก็บ หรือชื่อ
- **กู้คืน** — ติ๊กเลือกรายการแล้วกด "↩️ กู้คืนที่เลือก" เพื่อนำกลับสู่ตารางหลัก

ประเภทการจัดเก็บมี 3 แบบ: `ฉบับแก้ไข` (ผู้ประเมินบันทึกทับ), `ลบโดยผู้ดูแลระบบ`, `จัดเก็บภาคเรียน`

## 🧑‍🏫 ครูผู้รับการประเมิน
- เพิ่ม/แก้ไขทีละคน หรือกด **📥 นำเข้ารายชื่อ** เพื่อนำเข้าทีละหลายคน

### วิธีนำเข้ารายชื่อครูจากไฟล์
1. กด **📥 นำเข้ารายชื่อ** → แท็บ **อัปโหลดไฟล์ CSV / Excel**
2. กด **⬇️ ดาวน์โหลดเทมเพลต Excel** (หรือ CSV) แล้วกรอกข้อมูล
   - ลบตัวอย่าง 3 แถวสีเทาออกก่อน แล้วกรอกหนึ่งแถวต่อครูหนึ่งคน
   - ห้ามลบหรือเปลี่ยนชื่อแถวหัวตาราง
   - **รหัสครูเว้นว่างได้** ระบบจะสร้างให้อัตโนมัติ
3. ลากไฟล์มาวาง หรือกดเลือกไฟล์ (รองรับ `.xlsx .xls .ods .csv .tsv`)
4. ระบบจะแสดง**ตารางตรวจสอบ** แยกสถานะรายแถว
   - 🟢 **เพิ่มใหม่** · 🔵 **อัปเดต** · ⚪ **ข้าม** (ชื่อซ้ำ) · 🔴 **ผิดพลาด** (พร้อมเหตุผล)
5. ติ๊ก **"อัปเดตข้อมูลเดิมถ้าพบชื่อหรือรหัสครูซ้ำ"** ถ้าต้องการแก้ข้อมูลเดิมไปด้วย
6. กด **✅ นำเข้าข้อมูล**

> 💡 ระบบจับคู่คอลัมน์จากชื่อหัวตารางให้เอง จึงใช้ไฟล์ที่มีอยู่แล้วได้โดยไม่ต้องจัดเรียงใหม่
> รองรับชื่อคอลัมน์หลายแบบ เช่น "ระดับชั้น" / "ชั้น" / "level" และรองรับไฟล์ที่มีเฉพาะคอลัมน์
> "ชื่อ-นามสกุล" (ระบบแยกคำนำหน้าให้) รวมถึงไฟล์ CSV ภาษาไทยที่บันทึกจาก Excel แบบเดิม

- ยังใช้แท็บ **📋 วางข้อความ** คัดลอกจาก Excel มาวางได้เหมือนเดิม
  (คำนำหน้า | ชื่อ | นามสกุล | ระดับชั้น | เวรประจำวัน | อีเมล)
- **ประวัติ** — ดูคะแนนของครูรายคนข้ามภาคเรียน เพื่อดูพัฒนาการ
- ครูที่มีผลการประเมินแล้วจะลบไม่ได้ ให้เปลี่ยนสถานะเป็น "ไม่ใช้งาน" แทน เพื่อรักษาข้อมูลย้อนหลัง

## 👥 ผู้ประเมิน

หน้านี้มี 2 ส่วน — **บทบาทและขอบเขตการประเมิน** ด้านบน และ **รายชื่อผู้ประเมิน** ด้านล่าง

### 🎭 บทบาทและขอบเขตการประเมิน

โรงเรียนกำหนดเองได้ว่ามีบทบาทผู้ประเมินอะไรบ้าง ไม่ต้องแก้โค้ด
ระบบติดตั้งมาให้ 4 บทบาทมาตรฐาน และเพิ่มใหม่ได้ตามโครงสร้างจริงของโรงเรียน

กด **➕ เพิ่มบทบาท** แล้วเลือกว่าบทบาทนั้น **ประเมินครูกลุ่มใด**

| ประเภทขอบเขต | ประเมินครูกลุ่มใด | ตอนเพิ่มผู้ประเมินต้องระบุ |
|---|---|---|
| **ทุกคน** | ครูทุกคนในโรงเรียน | ไม่ต้องระบุ |
| **ระดับชั้น** | ครูที่ปรึกษาของระดับชั้นที่รับผิดชอบ | เลือกระดับชั้น |
| **เวรประจำวัน** | ครูที่อยู่เวรวันเดียวกัน ตามตารางเวรของภาคเรียนนั้น | เลือกวัน |
| **กลุ่มสาระ/ฝ่าย** | ครูในกลุ่มสาระหรือฝ่ายเดียวกัน | เลือกกลุ่มสาระ/ฝ่าย |
| **เลือกครูเอง** | เฉพาะครูที่เลือกไว้เป็นรายคน | ติ๊กเลือกรายชื่อครู |

ตัวอย่างบทบาทที่โรงเรียนมักเพิ่มเอง — *หัวหน้ากลุ่มสาระการเรียนรู้* (แบบกลุ่มสาระ/ฝ่าย),
*หัวหน้างานระบบดูแลช่วยเหลือนักเรียน* (แบบทุกคน), *คณะกรรมการเฉพาะกิจ* (แบบเลือกครูเอง)

> **ปิดใช้ หรือ ลบ?** ใช้ **ปิดใช้** เมื่อเลิกใช้บทบาทนั้นแล้วแต่ยังมีข้อมูลเก่าอยู่ —
> ข้อมูลย้อนหลังยังอ่านและออกรายงานได้ครบ
> **ลบ** ทำได้เฉพาะบทบาทที่ยังไม่มีผู้ประเมินและไม่เคยมีผลการประเมินเลย

**เปลี่ยนชื่อบทบาทได้อย่างปลอดภัย** — ระบบจะตามไปแก้ชื่อในทะเบียนผู้ประเมิน
กลุ่มผู้ประเมินของชุดประเมิน ผลการประเมิน และคลังข้อมูลย้อนหลังให้ครบโดยอัตโนมัติ

### เพิ่มผู้ประเมิน

กด **➕ เพิ่มผู้ประเมิน** แล้วกรอกชื่อ-นามสกุล อีเมล และเลือกบทบาท

- **ยังไม่มีบทบาทที่ต้องการ?** เลือก **"➕ เพิ่มบทบาทใหม่..."** ในช่องบทบาทได้เลย
  กรอกชื่อบทบาทและเลือกประเภทขอบเขต ระบบจะสร้างบทบาทให้พร้อมกับเพิ่มผู้ประเมินในครั้งเดียว
- **ยังไม่มีขอบเขตที่ต้องการ?** กด **"➕ ระบุเอง"** ข้างช่องขอบเขตแล้วพิมพ์ได้ทันที
  (เช่น ระดับชั้นใหม่ "ม.7" หรือกลุ่มสาระใหม่) — **ระบบจะจำไว้ให้เลือกจากรายการในครั้งถัดไป**
- บทบาทแบบ **เลือกครูเอง** จะมีช่องค้นหาและรายการติ๊กเลือกครู พร้อมตัวนับจำนวนที่เลือกไว้

ระบบสุ่มรหัสผ่านให้อัตโนมัติ ส่งเข้าอีเมลถ้ากรอกไว้ และบังคับเปลี่ยนรหัสผ่านเมื่อเข้าใช้ครั้งแรก

> ⚠️ หากเห็นแถบเตือน **"ผู้ประเมินใช้บทบาทที่ไม่มีอยู่ในรายการแล้ว"** แปลว่ามีผู้ประเมิน
> ที่บทบาทถูกลบหรือพิมพ์ชื่อไม่ตรง จึงยังประเมินใครไม่ได้ —
> ให้เพิ่มบทบาทนั้น หรือกด "แก้ไข" เพื่อเปลี่ยนบทบาทของผู้ประเมินให้ถูกต้อง

### ปุ่มอื่น ๆ ในรายชื่อผู้ประเมิน
- **🔑 รีเซ็ต** — ออกรหัสผ่านใหม่ให้ (ส่งเข้าอีเมลอัตโนมัติถ้ามี)
- **ปลดล็อก** — ปลดบัญชีที่ถูกล็อกจากการกรอกรหัสผ่านผิดหลายครั้ง
- **ปิดใช้ / ลบ** — ลบได้เฉพาะผู้ประเมินที่ยังไม่มีผลการประเมิน

## 📅 เวรประจำวันรายภาคเรียน
**ตารางเวรของแต่ละภาคเรียนแยกจากกันอย่างสมบูรณ์** — แก้ไขเวรของภาคเรียนใหม่
ได้โดยไม่กระทบข้อมูลและผลการประเมินของภาคเรียนก่อนหน้า

- **🪄 สร้างจากค่าเริ่มต้นในทะเบียนครู** — สร้างตารางเวรทั้งหมดในคลิกเดียว
- **📋 คัดลอกจากภาคเรียนอื่น** — เริ่มภาคเรียนใหม่จากของเดิมแล้วค่อยปรับ
- **➕ เพิ่มรายการเวร** — ระบุวัน บทบาทในเวร (หัวหน้าเวร/รองหัวหน้าเวร/กรรมการเวร)
  จุดปฏิบัติหน้าที่ เวลาเริ่ม-สิ้นสุด ระดับชั้นที่ดูแล และหมายเหตุ
- ส่วน "ครูที่ยังไม่มีเวรในภาคเรียนนี้" กดชื่อเพื่อเพิ่มได้ทันที

> การเปลี่ยนวันเวรมีผลต่อสิทธิ์ของ "หัวหน้าเวรประจำวัน" ในภาคเรียนนั้นทันที

## 🧩 ชุดประเมิน

**ชุดประเมิน** คือกล่องที่บรรจุ *เกณฑ์ + มาตราคะแนน + กลุ่มผู้ประเมิน* ของตัวเอง
ทำให้แยกการประเมินออกเป็นชุด ๆ ได้อิสระ เช่น

| ชุด | เกณฑ์ | เต็มต่อข้อ | คะแนนที่หน่วยงานได้รับ |
|---|---|---|---|
| การปฏิบัติงานกลุ่มบริหารงานกิจการนักเรียน | 10 ข้อ | 5 | 20 คะแนน |
| การปฏิบัติงานกลุ่มบริหารงานวิชาการ | 8 ข้อ | 4 | 30 คะแนน |

### สร้างชุดใหม่
กด **➕ สร้างชุดประเมิน** แล้วกรอก

| ช่อง | ความหมาย |
|---|---|
| ชื่อชุดประเมิน | ชื่อที่จะแสดงในหน้าจอและรายงาน |
| คะแนนเต็มต่อข้อ | มาตราที่ผู้ประเมินให้คะแนนในแต่ละข้อ (2–100 · ปกติ 5) |
| คะแนนที่หน่วยงานได้รับ | คะแนนเต็มที่จะแปลงไปใช้จริง (ใส่ 0 = ไม่แปลง) |
| ถ่วงน้ำหนักกลุ่มผู้ประเมิน | คิดคะแนนสุทธิจากน้ำหนัก % ของแต่ละกลุ่ม |
| ปรับสัดส่วนอัตโนมัติ | ครูที่ขาดการประเมินจากบางกลุ่มจะไม่เสียเปรียบ |
| ถ่วงน้ำหนักรายข้อ | ใช้คอลัมน์ "น้ำหนัก (%)" ของเกณฑ์แต่ละข้อ |

กล่องตัวอย่างใต้ช่องกรอกจะแสดงทันทีว่าคะแนนสุทธิเท่านั้นเท่านี้จะกลายเป็นกี่คะแนน

### กำหนดผู้ประเมินของชุด
กด **👥 ผู้ประเมิน** ที่การ์ดของชุดนั้น แล้วสร้าง "กลุ่ม" ได้ 2 แบบ

- **แบบบทบาท** — เลือกบทบาท (รวมหลายบทบาทในกลุ่มเดียวได้)
  ทุกคนที่มีบทบาทนั้นจะเป็นผู้ประเมินของกลุ่มโดยอัตโนมัติ
- **แบบรายบุคคล** — เลือกผู้ประเมินรายคน เหมาะกับคณะกรรมการเฉพาะกิจ
  **มีสิทธิ์เหนือกว่าแบบบทบาท** จึงใช้กำหนดทับเป็นรายกรณีได้

ใส่น้ำหนัก % ของแต่ละกลุ่ม (แนะนำให้รวมเป็น 100%) แล้วกดบันทึก

### ปุ่มอื่น ๆ ที่การ์ดของชุด
- **✏️ แก้ไข** — แก้ชื่อ มาตราคะแนน และการแปลงคะแนน
- **📝 เกณฑ์** — ไปที่หน้าเกณฑ์ของชุดนั้นโดยตรง
- **📋 คัดลอก** — สร้างชุดใหม่จากชุดเดิม พร้อมเกณฑ์และกลุ่มผู้ประเมินทั้งหมด
- **⏸️ ปิดใช้** — หยุดใช้ชุดนั้นโดยไม่ลบข้อมูล (ต้องเหลือชุดที่เปิดใช้อย่างน้อย 1 ชุด)
- **🗑️ ลบ** — แสดงเฉพาะชุดที่ยังไม่มีผลการประเมิน เพื่อไม่ให้ข้อมูลหาย

## 📝 เกณฑ์การประเมิน
เลือก **ชุดประเมิน** ที่ต้องการแก้ไขจากรายการด้านบนก่อน จากนั้น
แก้ไขชื่อเกณฑ์ กำหนดกลุ่มผู้มีสิทธิ์ประเมินแต่ละข้อ ตั้งน้ำหนัก เปิด/ปิดการใช้งาน และลบข้อได้
รองรับสูงสุด **20 ข้อต่อชุด** (ชุดหลักเริ่มต้นที่ 10 ข้อตามระบบเดิม)

> การลบเกณฑ์ไม่ได้ลบคะแนนที่บันทึกไว้แล้ว — คะแนนเดิมยังอยู่ครบในชีท "ผลการประเมิน"
> เพียงแต่จะไม่ถูกนำมาคิดในรายงานอีก

## 📆 ปีการศึกษาและภาคเรียน

ตั้งค่าได้อย่างอิสระ แยกจากกันทุกส่วน

- **ภาคเรียนที่ใช้งานอยู่** — เลือก *ปีการศึกษาปัจจุบัน* และ *ภาคเรียนปัจจุบัน* แยกกันคนละช่อง
  เปลี่ยนเฉพาะอย่างใดอย่างหนึ่งได้ ค่านี้เป็นค่าเริ่มต้นของทุกหน้า (แบบประเมิน ตารางเวร รายงาน)
- **ปีการศึกษาที่เปิดใช้งาน** — เพิ่มปีใหม่ได้ทันที หรือลบปีเก่าออกจากรายการ
  (การลบออกจากรายการ **ไม่ลบข้อมูลการประเมิน** เป็นเพียงการซ่อนจากตัวเลือก)
  ปีที่ตั้งเป็นปัจจุบันจะลบไม่ได้ และปีที่ตั้งใหม่จะถูกเพิ่มเข้ารายการให้อัตโนมัติ
- **ภาคเรียนที่เปิดใช้งาน** — เปิด/ปิดได้ตามที่โรงเรียนใช้จริง รองรับ **ภาคฤดูร้อน**
  สำหรับโรงเรียนที่มีการประเมินช่วงซัมเมอร์
- **ตารางข้อมูลของแต่ละภาคเรียน** — เห็นจำนวนผลการประเมิน ข้อมูลในคลัง รายการเวร
  จำนวนครูและผู้ประเมินของทุกภาคเรียนในหน้าเดียว พร้อมปุ่ม "ตั้งเป็นปัจจุบัน" และ "เคลียร์"

> การเปลี่ยนภาคเรียนปัจจุบัน **ไม่ลบและไม่ย้ายข้อมูลใด ๆ** เป็นเพียงการเปลี่ยนค่าเริ่มต้นของหน้าจอ

## 🧹 เคลียร์ข้อมูลการประเมิน

ใช้ล้างข้อมูลเมื่อสิ้นปีการศึกษา หรือเมื่อต้องการเริ่มต้นใหม่

**ขั้นที่ 1 — เลือกขอบเขต**
- **รายภาคเรียน** เช่น เฉพาะภาคเรียนที่ 1/2568
- **ทั้งปีการศึกษา** เช่น ทุกภาคเรียนของปี 2568
- **ข้อมูลการประเมินทั้งหมด**

จากนั้นเลือกว่าจะจัดการ *ตารางผลการประเมิน* (ข้อมูลที่ใช้งานอยู่), *คลังข้อมูลย้อนหลัง* หรือ *ทั้งสองส่วน*

**เลือกวิธีดำเนินการ**

| วิธี | ผลลัพธ์ | กู้คืน |
|---|---|---|
| **ย้ายเข้าคลังข้อมูล** (แนะนำ) | ย้ายออกจากตารางหลัก แต่ยังค้นย้อนหลังและออกรายงานได้ | ได้ที่หน้าคลังข้อมูล |
| **ลบถาวร** | ลบออกจากระบบทั้งหมด | ไม่ได้ |

**ขั้นที่ 2 — ตรวจสอบและยืนยัน**
- กด "🔍 ตรวจสอบข้อมูลที่จะได้รับผลกระทบ" เพื่อดูจำนวนรายการ จำนวนครู และผู้ประเมินที่เกี่ยวข้อง
- ติ๊ก **"สำรองเป็นไฟล์ Excel"** ก่อนลบถาวร (ระบบเปิดให้อัตโนมัติ) ไฟล์จะเก็บใน Google Drive
- ต้อง **พิมพ์ข้อความยืนยันให้ตรงทุกตัวอักษร** เช่น `2568/1` (รายภาคเรียน) หรือ `2568` (รายปี)
  ปุ่มดำเนินการจะกดได้ก็ต่อเมื่อพิมพ์ถูกต้อง
- ทุกการเคลียร์ถูกบันทึกลงประวัติการใช้งาน พร้อมชื่อไฟล์สำรอง

> 💡 **แนะนำ**: สิ้นภาคเรียนให้ใช้ "ย้ายเข้าคลังข้อมูล" ส่วน "ลบถาวร" ควรใช้เฉพาะกรณีข้อมูลทดสอบ
> หรือข้อมูลที่ผิดพลาดจริง ๆ และควรสำรองไฟล์ไว้ก่อนเสมอ

## ⚖️ น้ำหนักผู้ประเมิน (คะแนนสุทธิ)

กำหนดว่าคะแนนจากผู้ประเมินแต่ละกลุ่มมีความสำคัญเท่าใด **แยกตามชุดประเมิน**
(เลือกชุดที่ต้องการจากรายการมุมขวาบนของการ์ด)

1. เปิดสวิตช์ **"เปิดใช้การคิดคะแนนสุทธิแบบถ่วงน้ำหนัก"**
2. ปรับ % ของแต่ละกลุ่มด้วยแถบเลื่อนหรือพิมพ์ตัวเลข — แถบสีและสูตรจะอัปเดตทันที
   (มีปุ่มลัด "คืนค่าเริ่มต้น" และ "เท่ากันทุกกลุ่ม")
3. เลือกว่าจะ **ปรับสัดส่วนอัตโนมัติเมื่อขาดกลุ่มผู้ประเมิน** หรือไม่
   - **เปิด (แนะนำ)** — ครูที่ไม่ได้รับการประเมินจากบางกลุ่มจะไม่เสียเปรียบ
   - **ปิด** — กลุ่มที่ไม่มีคะแนนถือเป็น 0 คะแนน
4. กรอก **คะแนนที่หน่วยงานได้รับ** — คะแนนเต็มที่จะแปลงคะแนนสุทธิไปใช้จริง
   ข้อความใต้ช่องจะแสดงตัวอย่างการแปลงให้ทันที (ใส่ 0 = ไม่แปลง)
5. กด **🔍 ดูผลกระทบก่อนบันทึก** เพื่อเทียบคะแนน คะแนนที่ได้รับ และอันดับก่อน-หลัง
   (มีลูกศร ▲▼ บอกว่าอันดับของแต่ละคนเปลี่ยนไปกี่อันดับ)
6. พอใจแล้วจึงกด **💾 บันทึกน้ำหนัก**

**สูตรทั้งหมด**

```
คะแนนเฉลี่ยของกลุ่ม   = เฉลี่ยคะแนนที่ผู้ประเมินในกลุ่มเดียวกันให้
คะแนนสุทธิ            = Σ (คะแนนเฉลี่ยของกลุ่ม × น้ำหนักของกลุ่ม) ÷ Σ น้ำหนักที่ใช้จริง
คะแนนที่หน่วยงานได้รับ  = คะแนนสุทธิ ÷ คะแนนเต็มต่อข้อ × คะแนนเต็มที่หน่วยงานกำหนด
```

**ตัวอย่าง** ชุดเต็มข้อละ 5 คะแนน หน่วยงานให้ 20 คะแนน
น้ำหนัก รอง ผอ. 40% · หน.กิจการฯ 30% · หน.ระดับชั้น 20% · หน.เวรฯ 10%
ครูได้คะแนนเฉลี่ยจากแต่ละกลุ่ม 5.00, 4.00, 4.50, 3.00

- คะแนนสุทธิ = (5.00×40 + 4.00×30 + 4.50×20 + 3.00×10) ÷ 100 = **4.40**
- คะแนนที่หน่วยงานได้รับ = 4.40 ÷ 5 × 20 = **17.60 คะแนน**

ถ้ามีหลายชุด ระบบจะรวมคะแนนที่ได้รับของทุกชุดเป็นคะแนนรวมต่อครู 1 คน

เมื่อเปิดใช้งานแล้ว **คะแนนสุทธิ** จะถูกใช้ในแดชบอร์ด การจัดอันดับ การเรียงลำดับก่อนส่งออก
และรายงานที่ส่งออกจะมีคอลัมน์ "คะแนนสุทธิ" พร้อมแผ่นงาน **"วิธีคิดคะแนนสุทธิ"**
ที่แสดงน้ำหนักและตัวอย่างการคำนวณ ให้ตรวจสอบที่มาของคะแนนได้
โดยค่าเฉลี่ยรวมแบบเดิมยังแสดงคู่กันเสมอ

## 📈 ติดตามความคืบหน้า

หน้ารวมสำหรับ "เดินงาน" ให้จบภายในกำหนด

- **สถิติภาพรวม** — บันทึกแล้วกี่รายการจากทั้งหมด ผู้ประเมินทำครบกี่คน ค้างกี่คน
  ครูได้รับการประเมินครบทุกกลุ่มแล้วกี่คน และมีผู้ประเมินกี่คนที่ยังไม่มีอีเมลในระบบ
- **ตารางรายผู้ประเมิน** — เห็นเป็นรายชุดว่าใครค้างชุดใด เหลืออีกกี่คน คิดเป็นกี่ %
- **ตารางความครบถ้วนรายครู** — ครูคนใดยังขาดการประเมินจากกลุ่มใดของชุดใด
- **✉️ แจ้งเตือนผู้ประเมินที่ค้าง** — ส่งอีเมลถึงเฉพาะคนที่ยังทำไม่ครบ
  เลือกผู้รับได้เอง แนบข้อความเพิ่มเติมได้ ครั้งละไม่เกิน 50 คน
  อีเมลจะระบุความคืบหน้า รายการที่ค้าง กำหนดส่ง และลิงก์เข้าสู่ระบบให้อัตโนมัติ
- **⏱️ ตั้งค่ารอบการประเมิน** — ดูหัวข้อถัดไป

### ⏱️ รอบการประเมิน

| การตั้งค่า | ใช้ทำอะไร |
|---|---|
| เปิดให้ผู้ประเมินบันทึกผล | ปิดเมื่อสรุปผลแล้ว เพื่อไม่ให้มีการแก้ไขเพิ่ม |
| เปิดให้ประเมินตั้งแต่ / ถึงวันที่ | จำกัดช่วงเวลาที่รับผล (เว้นว่าง = ไม่จำกัด) |
| ล็อกภาคเรียนที่สรุปผลแล้ว | ปิดการบันทึก/แก้ไขของภาคเรียนนั้นถาวร (ยังอ่านและออกรายงานได้) |

ระบบตรวจสอบทุกเงื่อนไข **ที่ฝั่งเซิร์ฟเวอร์** ไม่ใช่แค่ซ่อนปุ่มบนหน้าจอ

## 🔎 ตรวจคุณภาพการประเมิน

ใช้ตรวจก่อนสรุปผล ว่ามีสัญญาณที่ทำให้ผลไม่สะท้อนความจริงหรือไม่
**ไม่ได้ตัดสินว่าใครผิด** แต่ช่วยให้ทบทวนกับผู้ประเมินได้ตรงจุด

| ข้อสังเกต | ความหมาย |
|---|---|
| ให้คะแนนเท่ากันทุกข้อ | อาจให้คะแนนตามความรู้สึกรวม แทนการพิจารณาแยกรายข้อ |
| ให้คะแนนสูง/ต่ำกว่าค่าเฉลี่ยของระบบ | ส่วนต่างตั้งแต่ 0.50 ขึ้นไป เทียบกับค่าเฉลี่ยของทุกการประเมิน |
| ให้คะแนนครูทุกคนเกือบเท่ากัน | การกระจาย (ส่วนเบี่ยงเบนมาตรฐาน) ใกล้ 0 — แยกครูเก่ง/ครูที่ควรพัฒนาไม่ออก |
| ไม่ได้เขียนข้อเสนอแนะเลย | ผลการประเมินไม่มีข้อมูลย้อนกลับให้ครูนำไปพัฒนา |

ท้ายหน้ายังแสดง **ครูที่ยังขาดการประเมินจากกลุ่มที่มีน้ำหนัก**
ซึ่งควรตามให้ครบก่อนสรุปผล เพราะคะแนนสุทธิจะคิดจากเฉพาะกลุ่มที่ประเมินจริง

## ⚙️ ตั้งค่าและความปลอดภัย
- ข้อมูลสำหรับรายงาน: ชื่อสถานศึกษา ผู้ลงนาม ตำแหน่ง
- เกณฑ์ตัดระดับผลการประเมิน (ดีเยี่ยม/ดีมาก/ดี/พอใช้)
- **อีเมลกู้คืนรหัสผ่าน** พร้อมปุ่มทดสอบส่งอีเมล ← ควรตั้งไว้เสมอ
- นโยบายความปลอดภัย: จำนวนครั้งที่กรอกผิดได้ ระยะเวลาล็อก อายุเซสชัน
- เปลี่ยนรหัสผ่านผู้ดูแลระบบ
- **🩺 สถานะระบบ** — ตรวจความพร้อมของทุกส่วน

## 🕘 ประวัติการใช้งาน

## รอบการทำงานที่แนะนำในแต่ละภาคเรียน

1. **ต้นภาคเรียน**
   - เมนู **📆 ปีการศึกษาและภาคเรียน** → ตั้งปีการศึกษา/ภาคเรียนปัจจุบัน
   - คัดลอกหรือสร้างตารางเวรของภาคเรียนใหม่ → ตรวจทะเบียนครูและผู้ประเมินให้เป็นปัจจุบัน
   - เมนู **🧩 ชุดประเมิน** → ตรวจว่าชุด เกณฑ์ กลุ่มผู้ประเมิน และคะแนนที่หน่วยงานได้รับถูกต้อง
   - เมนู **📈 ติดตามความคืบหน้า → ⏱️ ตั้งค่ารอบการประเมิน** → กำหนดช่วงวันที่เปิดให้ประเมิน
2. **ระหว่างภาคเรียน** — ผู้ประเมินเข้าประเมินผ่านลิงก์เว็บแอป
   ผู้ดูแลติดตามที่เมนู **📈 ติดตามความคืบหน้า** และกด **✉️ แจ้งเตือน** เมื่อใกล้ครบกำหนด
3. **ก่อนสรุปผล** — เมนู **🔎 ตรวจคุณภาพการประเมิน** → ทบทวนข้อสังเกตกับผู้ประเมิน
   และตามให้ครูได้รับการประเมินครบทุกกลุ่ม
4. **ปลายภาคเรียน** — ประมวลผลและส่งออก Excel/PDF เสนอผู้บริหาร
   และออก **🪪 รายงานรายบุคคล** เพื่อแจ้งผลให้ครูแต่ละคน
5. **ปิดภาคเรียน**
   - **⏱️ ล็อกภาคเรียน** ที่สรุปผลแล้ว เพื่อไม่ให้มีการแก้ไขย้อนหลัง
   - ใช้ "📦 จัดเก็บภาคเรียนนี้" ที่หน้าคลังข้อมูล หรือเมนู **🧹 เคลียร์ข้อมูลการประเมิน**
     เพื่อย้ายข้อมูลเข้าคลัง แล้วเปลี่ยนภาคเรียนปัจจุบันเพื่อเริ่มภาคเรียนถัดไป
