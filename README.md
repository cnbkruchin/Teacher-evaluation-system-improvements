# ระบบประเมินผลการปฏิบัติงานครู v3.0

ระบบประเมินผลการปฏิบัติงานครู กลุ่มบริหารงานกิจการนักเรียน — พัฒนาต่อยอดจากระบบเดิม (v2)
ทำงานบน **Google Sheets + Google Apps Script** ใช้งานได้ทั้งบนคอมพิวเตอร์ แท็บเล็ต และมือถือ

> ⚠️ **อัปเกรดจากระบบเดิมได้ทันที** — ข้อมูลครู ผู้ประเมิน รหัสผ่าน และผลการประเมินเดิม
> จะถูกย้ายมาให้อัตโนมัติโดยไม่สูญหาย (ดู [docs/MIGRATION.md](docs/MIGRATION.md))

---

## สิ่งที่ปรับปรุงจากระบบเดิม

| ด้าน | ระบบเดิม (v2) | ระบบใหม่ (v3) |
|---|---|---|
| **หน้าจอ** | หน้าต่างซ้อนแยกกัน 4 หน้า | เว็บแอปเดียว มีเมนูข้าง รองรับมือถือ มีโหมดกลางคืน |
| **ความปลอดภัย** | SHA-256 รอบเดียว, salt ร่วมกันทั้งระบบ | salt เฉพาะราย + วนแฮช 4,096 รอบ, ล็อกบัญชีเมื่อเดารหัส, เซสชันหมดอายุ, บันทึกประวัติทุกการกระทำ |
| **ลืมรหัสผ่าน admin** | ไม่มี (ต้องแก้ชีทเอง) | 3 ช่องทาง: OTP ทางอีเมล / เมนูเจ้าของไฟล์ / รันฟังก์ชันฉุกเฉิน |
| **รายงาน** | สรุปลงชีทเท่านั้น | ส่งออก **Excel (.xlsx)** และ **PDF** พร้อมหัวรายงานและช่องลงนาม |
| **การส่งออก** | ส่งออกทั้งหมดเสมอ | **เลือกและจัดลำดับผู้ถูกประเมินเองก่อนประมวลผล** (ลากสลับตำแหน่งได้) |
| **เวรประจำวัน** | ผูกกับตัวครู 1 ค่า | **แยกอิสระตามภาคเรียน** เก็บบทบาทในเวร จุดปฏิบัติหน้าที่ และเวลา |
| **ข้อมูลย้อนหลัง** | ลบแล้วหายถาวร | **คลังข้อมูล** เก็บทุกฉบับที่ถูกแก้ไข/ลบ/ปิดภาคเรียน และกู้คืนได้ |
| **เกณฑ์การประเมิน** | แก้ได้เฉพาะในโค้ด | แก้ไข เพิ่ม ปิดใช้ และตั้งน้ำหนักได้จากหน้าจอ |
| **คะแนน** | เก็บเป็นสูตรในชีท (พังเมื่อย้ายข้อมูล) | คำนวณและเก็บเป็นค่าคงที่ ตรวจสอบย้อนหลังได้เสมอ |

## ความสามารถหลัก

### สำหรับผู้ดูแลระบบ
- **แดชบอร์ด** — สถิติภาพรวม กราฟ 4 ชุด ความคืบหน้าของผู้ประเมินรายคน อันดับคะแนน
- **ผลการประเมิน** — ค้นหา/กรองตามปี ภาคเรียน ระดับชั้น วันเวร ดูคะแนนรายข้อและประวัติการแก้ไข
- **ประมวลผลและส่งออก** — เลือกผู้ถูกประเมิน จัดลำดับเอง (ลาก/ปุ่มเลื่อน) หรือใช้การเรียงอัตโนมัติ
  → ดูตัวอย่างก่อน → ส่งออก Excel / PDF / ทั้งสองแบบ
- **คลังข้อมูลย้อนหลัง** — ปิดภาคเรียน ค้นหาข้อมูลเก่า และกู้คืนกลับได้
- **ข้อมูลหลัก** — ครู (เพิ่ม/นำเข้าจาก Excel), ผู้ประเมิน (สุ่มรหัสผ่าน + ส่งอีเมลอัตโนมัติ),
  เวรประจำวันรายภาคเรียน, เกณฑ์การประเมิน
- **ตั้งค่าและความปลอดภัย** — ปีการศึกษา เกณฑ์ตัดระดับ อีเมลกู้คืนรหัสผ่าน นโยบายเซสชัน
- **ประวัติการใช้งาน** — บันทึกทุกการเข้าสู่ระบบและการแก้ไขข้อมูล

### สำหรับผู้ประเมิน
- เห็นเฉพาะครูและเกณฑ์ตามสิทธิ์ของตนเอง (รอง ผอ. / หัวหน้ากลุ่มฯ / หัวหน้าระดับชั้น / หัวหน้าเวร)
- แบบประเมินแสดงความคืบหน้า มีปุ่มให้คะแนนรวดเร็ว ค้นหาชื่อครูได้
- แก้ไขผลที่เคยบันทึกได้ — ระบบเก็บฉบับเดิมไว้ในคลังข้อมูลเสมอ
- ดูตารางเวรประจำวันของภาคเรียน และเปลี่ยนรหัสผ่านด้วยตนเอง

## เริ่มต้นใช้งานอย่างรวดเร็ว

1. เปิดไฟล์ Google Sheets ของระบบ → เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. คัดลอกไฟล์ทั้งหมดในโฟลเดอร์ [`src/`](src) เข้าโปรเจกต์ (ดูวิธีละเอียดใน [docs/INSTALL.md](docs/INSTALL.md))
3. กลับมาที่ Google Sheets → รีเฟรชหน้า → เมนู **🏫 ระบบประเมินผล → ⚙️ ติดตั้ง / อัปเกรดระบบ**
4. จดรหัสผ่านผู้ดูแลระบบที่ระบบแสดงให้
5. เมนู **🏫 ระบบประเมินผล → 🚀 เปิดระบบ** → เข้าสู่ระบบผู้ดูแล
6. ไปที่ **ตั้งค่าและความปลอดภัย** → กรอก **อีเมลกู้คืนรหัสผ่าน** แล้วกดทดสอบส่งอีเมล
7. เพิ่มรายชื่อครู → ผู้ประเมิน → ตารางเวรประจำวัน แล้วส่งลิงก์เว็บแอปให้ผู้ประเมิน

## โครงสร้างโปรเจกต์

```
src/                      โค้ดที่ใช้งานจริง (อัปโหลดขึ้น Apps Script)
├── appsscript.json       สิทธิ์การเข้าถึงและการตั้งค่าเว็บแอป
├── 00_Config.gs          ค่าคงที่ ชื่อชีท บทบาท เกณฑ์เริ่มต้น
├── 01_Data.gs            อ่าน/เขียนชีทโดยอ้างอิงชื่อคอลัมน์
├── 02_Security.gs        เข้ารหัสรหัสผ่าน เซสชัน จำกัดการล็อกอิน
├── 03_Setup.gs           ติดตั้ง/อัปเกรด และย้ายข้อมูลจากระบบเดิม
├── 04_Domain.gs          เกณฑ์ การคำนวณคะแนน เวรประจำวันรายภาคเรียน
├── 05_Auth.gs            เข้าสู่ระบบ/ออกจากระบบ/เปลี่ยนรหัสผ่าน
├── 06_Recovery.gs        กู้คืนรหัสผ่านผู้ดูแลระบบ (3 ช่องทาง)
├── 07_EvaluatorApi.gs    ฟังก์ชันสำหรับผู้ประเมิน
├── 08_AdminApi.gs        ฟังก์ชันสำหรับผู้ดูแลระบบ
├── 09_Reports.gs         ประมวลผลและส่งออก Excel/PDF
├── 10_Archive.gs         คลังข้อมูลย้อนหลัง
├── 11_WebApp.gs          จุดเริ่มต้นเว็บแอปและเมนู
├── 12_SelfTest.gs        ทดสอบตรรกะระบบจาก Apps Script Editor
├── Index.html            โครงหน้าจอ
├── Styles.html           ชุดรูปแบบ (รองรับโหมดสว่าง/มืด)
├── AppJs.html            แกนกลาง: เรียก API, เซสชัน, แจ้งเตือน
├── AdminJs.html          แดชบอร์ด ผลการประเมิน คลังข้อมูล ประวัติ
├── AdminDataJs.html      ครู ผู้ประเมิน เวรประจำวัน เกณฑ์ ตั้งค่า
├── AdminExportJs.html    เลือก/จัดลำดับ/ประมวลผล/ส่งออก
└── EvaluatorJs.html      หน้าจอผู้ประเมิน

docs/                     คู่มือการติดตั้ง ใช้งาน ความปลอดภัย และการย้ายข้อมูล
tests/                    ชุดทดสอบอัตโนมัติ (รันด้วย Node.js)
legacy/                   ซอร์สโค้ดระบบเดิม (v2) เก็บไว้อ้างอิง
```

## ชีทข้อมูลในระบบ

| ชีท | เก็บอะไร |
|---|---|
| `รายชื่อครู` | ทะเบียนครูผู้รับการประเมิน |
| `ผู้ประเมิน` | บัญชีผู้ประเมิน (ซ่อนไว้ — มีค่าแฮชรหัสผ่าน) |
| `เกณฑ์การประเมิน` | เกณฑ์ ผู้มีสิทธิ์ประเมิน และน้ำหนัก |
| `เวรประจำวันรายภาคเรียน` | ตารางเวร แยกตามปีการศึกษา/ภาคเรียน |
| `ผลการประเมิน` | ผลการประเมินที่ใช้งานอยู่ |
| `คลังผลการประเมิน` | ข้อมูลย้อนหลังทั้งหมด (ฉบับแก้ไข/ถูกลบ/ปิดภาคเรียน) |
| `สรุปผลการประเมิน` | ผลสรุปรายบุคคลที่สั่งประมวลผล |
| `ประวัติการใช้งาน` | บันทึกการใช้งานระบบ (audit log) |
| `ตั้งค่าระบบ` | การตั้งค่าและรหัสผ่านผู้ดูแล (ซ่อนไว้) |

## การทดสอบ

```bash
bash tests/run-all.sh      # ต้องมี Node.js 18 ขึ้นไป
```

ชุดทดสอบจำลอง Google Apps Script ทั้งหมดไว้ในหน่วยความจำ จึงรันได้โดยไม่ต้องเชื่อมต่อ Google
ครอบคลุมการติดตั้ง สิทธิ์ตามบทบาท การคำนวณคะแนน เวรรายภาคเรียน คลังข้อมูล การส่งออก
ความปลอดภัย การกู้คืนรหัสผ่าน และการย้ายข้อมูลจากระบบเดิม (รวม **125 รายการ**)

ตรวจสอบระบบที่ติดตั้งจริงได้จากเมนู **🩺 ตรวจสุขภาพระบบ**
หรือรันฟังก์ชัน `runSelfTest()` ใน Apps Script Editor
