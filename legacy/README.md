# ระบบเดิม (v2.0) — เก็บไว้เพื่ออ้างอิง

โฟลเดอร์นี้เก็บซอร์สโค้ดของระบบเดิมไว้ตามต้นฉบับ เพื่อใช้เปรียบเทียบและตรวจสอบย้อนหลัง
**ไม่ต้องอัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้น Apps Script** — โค้ดที่ใช้งานจริงอยู่ในโฟลเดอร์ `src/`

| ไฟล์ | คำอธิบาย |
|---|---|
| `Code.v2.gs` | สคริปต์ฝั่งเซิร์ฟเวอร์ของระบบเดิม |
| `AdminLogin.v2.html` | หน้าเข้าสู่ระบบผู้ดูแลระบบเดิม |
| `AdminPanel.v2.html` | แผงควบคุมผู้ดูแลระบบเดิม |
| `EvaluatorLogin.v2.html` | หน้าเข้าสู่ระบบผู้ประเมินเดิม |
| `EvaluationForm.v2.html` | แบบฟอร์มประเมินเดิม |

ข้อมูลที่บันทึกไว้แล้วด้วยระบบเดิมสามารถย้ายเข้าสู่ระบบใหม่ได้ด้วยเมนู
**🏫 ระบบประเมินผล → ⚙️ ติดตั้ง/อัปเกรดระบบ** ซึ่งจะทำการ migrate ให้อัตโนมัติ
(ดูรายละเอียดใน `docs/MIGRATION.md`)
